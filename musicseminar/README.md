# musicseminar（コード理論ゼミ）

musiclab の 3 曲「スーパーハスタワー」「ウルトラハスタワー」「戦闘曲 1 改『ハスタワー』」を教材にした、コード理論初心者向けの 60 分ゼミの発表資料です。
音の定義から始めて、代表的なコード進行と「外し」（偽終止・セカンダリードミナント・借用和音・転調）を、原曲のその場面を鳴らしながら学びます。

## 動かす

スライドは `../musiclab/` の再生エンジンと曲を読み込むため、**リポジトリのいちばん上（`hustower/`）**でローカルサーバーを立てます（musiclab の README とは場所が違うので注意）。

```sh
uv run python -m http.server 8000
```

http://localhost:8000/musicseminar/ を開きます。

| キー | 動き |
| --- | --- |
| → / PageDown | 次のスライド（プレゼン用のクリッカーでも送れる） |
| ← / PageUp | 前のスライド |
| Space | 音が鳴っていれば止める。鳴っていなければ次へ |
| Esc | 音を止める |
| N | 発表者メモ（話すこと・時間が押したときの省き方）を表示 / 非表示 |
| T | 経過時間をリセット |

- **♪ ボタン**: 説明用の音（周波数・音階・和音・進行）。進行はチップの色が役割を表す（青 = T、緑 = SD、赤 = D、紫 = 音階の外の和音）
- **▶ ボタン**: 原曲の指定セクションを、指定した小節数だけ鳴らす。いま鳴っているコードのチップが光る
- 鍵盤は押しても鳴る
- 下の帯に経過時間と「このパートの目安」が出る。目安を過ぎると赤くなる
- URL の `#12` で 12 枚目から開ける（再読み込みしても同じスライドに戻る）

## タイムテーブル（60 分）

| 時間 | パート | スライド | 内容 |
| --- | --- | --- | --- |
| 0–4 | はじめに | 1–3 | ゴール / スーパーの C メロ → 大サビを聴く（答えは最後に） |
| 4–9 | 第 1 部 音の正体 | 4–5 | 周波数・オクターブ・12 音・半音と全音 |
| 9–15 | 第 2 部 音階とキー | 6–8 | 長音階・短音階・平行調・ディグリー |
| 15–23 | 第 3 部 和音 | 9–12 | メジャー / マイナー・ダイアトニックコード・セブンス・分数コード |
| 23–31 | 第 4 部 役割（機能） | 13–16 | T / SD / D・ドミナントモーション・代理・カデンツ |
| 31–45 | 第 5 部 名前の付いた進行 | 17–22 | 王道・Axis・小室・丸サ・短調の 3 つ・♭VI–♭VII–I |
| 45–55 | 第 6 部 外し | 23–28 | 偽終止・セカンダリードミナント・借用和音・転調（28 枚目はおまけ） |
| 55–59 | 第 7 部 クイズ | 29–32 | 4 問。4 問目で冒頭の曲の答え合わせ |
| 59–60 | まとめ | 33 | 聴くときのチェックリスト |

時間が押したときは、発表者メモにある順で削ります（第 5 部は原曲を 1 つに絞る、28 枚目のおまけを飛ばす）。

## 事前チェック

- 本番の PC・スピーカーで、3 枚目の ▶ を一度押して音量を合わせる（初回は曲の読み込みに少しかかる）
- 曲が読み込めないと画面の上に赤い表示が出る。サーバーをリポジトリのいちばん上で立てているか確認する
- 配布資料は [handout.md](handout.md)（進行の早見表とクイズの記入欄）

## 構成

```
index.html    スライド（33 枚）。発表者メモは各スライドの <aside class="notes">
seminar.css   見た目（1280×720 の舞台を画面に合わせて拡大縮小。ダークモード対応）
seminar.js    スライド送り・説明用のシンセ・原曲の部分再生・クイズ
handout.md    配布用の早見表
```

原曲の再生は `../musiclab/lib/engine.js` と各スケッチの `SECTIONS` を使います。曲のセクション名を変えたら、`index.html` の `data-section` も合わせてください（合わないと、そのボタンの所に「読み込めません」と出ます）。
