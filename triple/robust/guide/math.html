数学的に定式化すると

ロバスト制御の基本的な対象は、右半平面で有界な解析関数の空間 \(H_\infty\) と、その中の作用素としてのフィードバック結合である。デモの H∞ 制御器は、ばねの強さの不確かさを線形分数変換で表し、DGKF の状態空間公式を行列符号関数で解いて合成している。

1. H∞ ノルムと誘導ノルム

定義 1 \(H_\infty^{p\times m}\) を開右半平面 \(\mathbb{C}_+\) で解析的かつ有界な \(p\times m\) 行列値関数の空間とし、\(\|G\|_\infty = \sup_{s\in\mathbb{C}_+}\bar\sigma(G(s))\) とする（\(\bar\sigma\) は最大特異値）。有理関数については最大値原理により \(\|G\|_\infty = \sup_{\omega\in\mathbb{R}}\bar\sigma(G(j\omega))\)。実有理なものの全体を \(\mathcal{RH}_\infty\) と書く。
命題 2 \(G\in H_\infty\) の定める因果的な畳み込み作用素 \(\mathcal{G}: L^2(0,\infty)\to L^2(0,\infty)\) について \(\|\mathcal{G}\|_{L^2\to L^2} = \|G\|_\infty\)。

ペイリー・ウィーナーの定理により \(L^2(0,\infty)\) はフーリエ変換で \(H_2\) と等長同型で、\(\mathcal{G}\) は掛け算作用素 \(\hat u\mapsto G\hat u\) に対応する。掛け算作用素のノルムは \(\operatorname{ess\,sup}_\omega\bar\sigma(G(j\omega))\)。等号は \(\bar\sigma\) を達成する周波数の近くに集中した入力で近似的に達成される。

したがって \(\|G\|_\infty\) は「エネルギー有限のあらゆる入力に対する、出力のエネルギーの最悪の倍率」である。LQG（\(H_2\) ノルム）が白色雑音に対する平均的な応答を測るのとの違いはここにある。

2. 小ゲイン定理

定理 3（小ゲイン定理） \(M\in\mathcal{RH}_\infty^{p\times q}\)、\(\Delta\in\mathcal{RH}_\infty^{q\times p}\) を正のフィードバックで結ぶ（\(w = \Delta z,\ z = Mw + \text{外部入力}\)）。\(\|M\|_\infty\|\Delta\|_\infty < 1\) なら、結合は適切（well-posed）かつ内部安定である。逆に、\(\|M\|_\infty \ge 1\) なら、\(\|\Delta\|_\infty \le 1\) を満たす（複素の、構造のない）\(\Delta\in\mathcal{RH}_\infty\) で閉ループを不安定にするものが存在する。

十分性：閉右半平面のすべての \(s\) で \(\bar\sigma(M(s)\Delta(s)) < 1\) なので \(\det(I - M\Delta)\) は閉右半平面で零点を持たず、\((I - M\Delta)^{-1}\in\mathcal{RH}_\infty\)（ノイマン級数）。必要性：\(\bar\sigma(M(j\omega_0)) \ge 1\) とし、特異値分解 \(M(j\omega_0) = U\Sigma V^*\) の最大特異値のベクトルを用いて \(\Delta(j\omega_0) = \sigma_1^{-1}v_1u_1^*\) とすると \(\det(I - M\Delta)(j\omega_0) = 0\)。この複素ベクトルを、虚軸上で \(j\omega_0\) を通る安定な実有理関数（1 次の全域通過関数の組み合わせ）で補間すればよい。

これは作用素論の形でも成り立つ（\(M, \Delta\) が \(L^2_e\) 上の因果的で有限ゲインの作用素なら、ゲインの積が 1 未満で入出力安定）。非線形・時変の \(\Delta\) にも使えることが、この定理の強さである。

3. 線形分数変換による不確かさの表現

デモの対象は \(m_1 = m_2 = 1\)、状態 \(x = (x_1, x_2, v_1, v_2)\)、

$$ \dot x = A(k)x + B_uu + B_ww,\qquad A(k) = \begin{pmatrix}0&0&1&0\\0&0&0&1\\-k&k&0&0\\k&-k&0&0\end{pmatrix},\qquad y = x_2 + \sigma n. $$

\(k = k_0 + d_k\delta\)（\(|\delta|\le 1\)）と書くと \(A(k) = A(k_0) + d_k\delta\,b_\Delta c_\Delta\)、\(b_\Delta = (0,0,-1,1)^\top\)、\(c_\Delta = (1,-1,0,0)\)。正の数 \(\alpha\) を任意にとり

$$ z_\Delta = \sqrt{d_k}\,\alpha\, c_\Delta x,\qquad w_\Delta = \delta\,z_\Delta,\qquad \dot x \ni \frac{\sqrt{d_k}}{\alpha}\,b_\Delta\,w_\Delta $$

とおけば、元の系は名目の系と \(\delta\) の正帰還結合（上側の線形分数変換 \(\mathcal{F}_u(G, \delta)\)）になる。\(z_\Delta\) から \(w_\Delta\) までの閉ループの部分伝達関数 \(T_{z_\Delta w_\Delta}\) は \(\alpha\) によらず、定理 3 から

$$ \|T_{z_\Delta w_\Delta}\|_\infty < 1 \ \Longrightarrow\ |\delta|\le 1 \text{ のすべてで内部安定（すなわち } k\in[k_0 - d_k,\,k_0 + d_k]\text{）}. $$

デモは性能の通り道（外乱 \(w_d\) から位置・速度 \(z_x\)、力 \(z_u\)）も同じ一般化プラントに入れ、全体の \(\|T_{zw}\|_\infty < \gamma\) を課す。部分ブロックのノルムは全体のノルム以下なので、\(\gamma \le 1\) なら上の保証が得られ、一般に \(|\delta| < 1/\gamma\)、つまり \(k\in[k_0 - d_k/\gamma,\,k_0 + d_k/\gamma]\) で安定が保証される。\(\alpha\) は不確かさの通り道と性能の通り道の重みの比を変え、合成される制御器を変える（一種の D スケーリング）が、保証の意味は変えない。

4. H∞ 制御問題と DGKF の定理

一般化プラント

$$ \dot x = Ax + B_1w + B_2u,\qquad z = C_1x + D_{12}u,\qquad y = C_2x + D_{21}w $$

について、次を仮定する。(A1) \((A, B_2)\) 可安定、\((C_2, A)\) 可検出。(A2) \(D_{12}^\top[C_1\ D_{12}] = [0\ I]\)、\(\begin{pmatrix}B_1\\D_{21}\end{pmatrix}D_{21}^\top = \begin{pmatrix}0\\I\end{pmatrix}\)。(A3) \((A, B_1)\) 可安定化可能、\((C_1, A)\) 可検出（あるいは、より弱く、2 つのハミルトン行列が虚軸上に固有値を持たないこと）。デモでは \(z_u = \rho_u u\) と \(y/\sigma\) の正規化によって (A2) を満たしている。

定理 4（Doyle–Glover–Khargonekar–Francis, 1989） \(\gamma > 0\) に対し、\(\|T_{zw}\|_\infty < \gamma\) を満たす内部安定化の動的出力フィードバックが存在することと、次の 3 条件は同値である。
  1. \(A^\top X + XA + X(\gamma^{-2}B_1B_1^\top - B_2B_2^\top)X + C_1^\top C_1 = 0\) が安定化解 \(X_\infty \succeq 0\) を持つ。
  2. \(AY + YA^\top + Y(\gamma^{-2}C_1^\top C_1 - C_2^\top C_2)Y + B_1B_1^\top = 0\) が安定化解 \(Y_\infty \succeq 0\) を持つ。
  3. \(\rho(X_\infty Y_\infty) < \gamma^2\)。
このとき「中心制御器」は \(F = -B_2^\top X_\infty\)、\(L = -Y_\infty C_2^\top\)、\(Z = (I - \gamma^{-2}Y_\infty X_\infty)^{-1}\) として $$ \dot{\hat x} = (A + \gamma^{-2}B_1B_1^\top X_\infty + B_2F + ZLC_2)\hat x - ZLy,\qquad u = F\hat x. $$

証明は、\(X_\infty\) に関する平方完成で「最悪の外乱」\(w^* = \gamma^{-2}B_1^\top X_\infty x\) と状態フィードバックの解を得て、残りの推定問題を双対の形で \(Y_\infty\) に帰着させ、両者の結合条件が 3. になる、という流れである（Doyle et al. 1989、Zhou–Doyle–Glover 第 16 章）。\(\gamma \to \infty\) の極限で制御器は LQG（\(H_2\) 最適）制御器に一致する。

達成可能な \(\gamma\) の下限 \(\gamma_{\mathrm{opt}}\) は、上の条件の成否に関する二分探索で求める。デモはさらに、\(\gamma \le 0.98\) を保てる範囲で性能の重みの倍率を二分探索で最大化し、\(\alpha\in\{1, 1.7, 3\}\) から \(\gamma\) が最小のものを選んでいる。

5. リッカチ方程式と行列符号関数

ハミルトン行列 \(H = \begin{pmatrix}A & R\\ -Q & -A^\top\end{pmatrix}\)（\(R, Q\) 対称）は \(JH\) が対称（\(J = \begin{pmatrix}0&I\\-I&0\end{pmatrix}\)）なので、固有値は \(\lambda\) と \(-\bar\lambda\) が対になる。虚軸上に固有値がなければ、安定な \(n\) 次元不変部分空間 \(\mathcal{X}_-(H)\) が存在し、それが \(\operatorname{Im}\begin{pmatrix}I\\X\end{pmatrix}\) の形なら、\(X\) は \(A^\top X + XA + XRX + Q = 0\) の安定化解である（\(A + RX\) が安定）。

定義 5（行列符号関数） 虚軸上に固有値を持たない \(H\) をジョルダン分解 \(H = T\begin{pmatrix}J_-&0\\0&J_+\end{pmatrix}T^{-1}\)（\(J_\mp\) の固有値は左／右半平面）として、\(\operatorname{sign}(H) = T\begin{pmatrix}-I&0\\0&I\end{pmatrix}T^{-1}\)。
命題 6 ニュートン反復 \(Z_0 = H\)、\(Z_{k+1} = \tfrac12(c_kZ_k + c_k^{-1}Z_k^{-1})\)、\(c_k = |\det Z_k|^{-1/(2n)}\) は \(\operatorname{sign}(H)\) に（最終的に）二次収束する。\(S = \operatorname{sign}(H) = \begin{pmatrix}S_{11}&S_{12}\\S_{21}&S_{22}\end{pmatrix}\) とすると、安定化解は $$ \begin{pmatrix}S_{12}\\ S_{22} + I\end{pmatrix}X = -\begin{pmatrix}S_{11} + I\\ S_{21}\end{pmatrix} $$ の（一意な、最小二乗の意味での）解である。

反復は各固有値に対してスカラーのニュートン法 \(z\mapsto\tfrac12(z + z^{-1})\) を適用することに等しく、これは \(\operatorname{Re}z \gtrless 0\) に応じて \(\pm1\) に二次収束する（行列式によるスケーリングは初期の収束を速める）。\(\tfrac12(I - S)\) は \(\mathcal{X}_-(H)\) への射影なので、\(S\begin{pmatrix}I\\X\end{pmatrix} = -\begin{pmatrix}I\\X\end{pmatrix}\)。これを書き下すと上の式。

デモでは、反復が収束しない（虚軸上の固有値が疑われる）か、解の残差が大きいか、\(X\) が半正定値でない場合を「\(\gamma\) は達成不可能」と判定している。LQR とカルマンフィルタのリッカチ方程式（\(R \preceq 0\) の場合）も同じ関数で解いている。

6. LQR の余裕と LQG の余裕

定理 7（LQR の余裕、1 入力の場合） \(u = -Kx\) が連続時間の LQR（\(Q\succeq 0\)、\(R = r > 0\)）なら、ループ伝達関数 \(L(s) = K(sI - A)^{-1}B\) は \(|1 + L(j\omega)| \ge 1\) を満たす。したがってゲイン余裕は \([1/2, \infty)\)、位相余裕は \(60^\circ\) 以上。

リッカチ方程式を変形すると「リターン差の等式」\((1 + L(-j\omega))r(1 + L(j\omega)) = r + B^\top(-j\omega I - A^\top)^{-1}Q(j\omega I - A)^{-1}B\) を得る。右辺は \(\ge r\) なので \(|1 + L| \ge 1\)。命題 8（古典制御の解説）を \(s_m = 1\) に適用する。

カルマンフィルタを挟んだ LQG にはこの種の保証がない。ドイル（1978）は、状態推定器のゲインを大きくしていくと、対象の入力端での余裕が任意に小さくなる例を示した（論文の要旨は "There are none."）。デモの LQG（名目値 \(k = 1.25\) で設計）では、入力端で切ったループの位相余裕は約 \(1^\circ\)、ゲイン余裕は約 0.1 dB で、小ゲイン定理が保証する \(k\) の範囲は \(1.24\)〜\(1.26\) にすぎない。

7. 保守性と構造化特異値 μ

定義 8 構造の集合 \(\boldsymbol{\Delta}\)（ブロック対角、実または複素）に対して $$ \mu_{\boldsymbol\Delta}(M) = \Big(\min\{\bar\sigma(\Delta) : \Delta\in\boldsymbol\Delta,\ \det(I - M\Delta) = 0\}\Big)^{-1} $$ （そのような \(\Delta\) がなければ 0）。

複素で構造のない \(\Delta\) なら \(\mu = \bar\sigma(M)\)（小ゲイン定理そのもの）、スカラーの複素 \(\delta I\) なら \(\mu = \rho(M)\)。一般に \(\rho_{\boldsymbol\Delta}(M) \le \mu_{\boldsymbol\Delta}(M) \le \inf_{D}\bar\sigma(DMD^{-1})\)（\(D\) は構造と可換な正定値行列）で、上界が D スケーリングである。デモの不確かさは実数のスカラー \(\delta\) なので、各周波数で安定性を失うのは \(T_{z_\Delta w_\Delta}(j\omega)\) が正の実数 \(1/\delta\) に等しくなるときに限られる。複素の小ゲイン条件 \(|T(j\omega)| < 1\) はこれよりはるかに強く、デモで H∞ 制御器が実際に安定な範囲（およそ 0.4〜3）が保証範囲（0.48〜2.02）より広いのはこのためである。実数の μ の計算は一般に NP 困難であることが知られている（Braatz–Young–Doyle–Morari, 1994）。
