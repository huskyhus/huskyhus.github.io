# 制御工学の見取り図（triple）

「思いどおりに動かす」ための 5 つの考え方を、それぞれ動くデモと解説で紹介する静的サイト。HTML / CSS / JavaScript だけで動き、最適化・リッカチ方程式・H∞ 制御器の合成・二次計画法・強化学習まで、計算はすべてブラウザの中で行う。`index.html`（見取り図）を開けばよい。

## 構成

| シリーズ | 題材 | デモでブラウザが計算しているもの |
| --- | --- | --- |
| [classical/](classical/) 古典制御 | ロボット関節のサーボ（2 慣性系） | PID ＋ノッチ、ボード線図、ナイキスト線図、安定余裕、閉ループの極（むだ時間はパデ近似）、飽和と積分の巻き上がり |
| [modern/](modern/) 現代制御 | 三重倒立振り子 | 振り上げの最適軌道（多重シューティング＋SQP、区分 BFGS、フィルタ法、継続法）、時変 LQR、LQR、EKF、雑音・モデル誤差・むだ時間、倒れたときの立て直し |
| [robust/](robust/) ロバスト制御 | ばねでつながった 2 台車（Wie–Bernstein のベンチマークに倣う） | LQG、H∞（DGKF の公式、行列符号関数によるリッカチ方程式、γ の二分探索、D スケーリング）、小ゲイン条件、k を走査した安定範囲 |
| [mpc/](mpc/) モデル予測制御 | 高速道路の車線変更と障害物回避 | 縮約した QP を 0.1 秒ごとに主双対内点法（メロトラ）で解く、終端費用は離散リッカチの解、ソフト制約、LQR ＋飽和との比較、横滑りする車（2 輪モデル）でのモデル誤差 |
| [rl/](rl/) 強化学習 | 谷から出られない非力な台車（mountain car と同じ力学） | Sarsa(λ)、タイルコーディング、価値関数と方策の可視化、人の規則との比較 |

各シリーズは `index.html`（デモ）と `guide/`（解説 8 ページ）からなる。解説の 1〜7 ページは制御工学を知らない人向け、8 ページ目（`math.html`）は数学科の博士課程程度の読者向けに、定義・定理・証明の概略で書いた定式化。

## ファイル

| 場所 | 中身 |
| --- | --- |
| `index.html` | 見取り図（シリーズの紹介、年表、比較表、サイトマップ） |
| `js/site.js` | サイト全体の構成（シリーズとページの一覧）と、上のバー・ページ送り・目次・サイトマップの描画 |
| `js/linalg.js` `js/lti.js` `js/plot.js` | 共通の行列計算（行列指数関数、離散リッカチ方程式の倍化法、固有値）、線形時不変系（周波数応答、パデ近似、シミュレーション）、キャンバスの描画 |
| `js/model.js` `js/planner.js` `js/control.js` `js/main.js` `js/guide-demos.js` | 現代制御（三重振り子） |
| `js/classical/` `js/robust/` `js/mpc/` `js/rl/` | 各シリーズの計算（`servo.js` `core.js`）、デモの画面（`demo.js`）、解説の動く図（`figs.js`） |
| `css/style.css` `css/guide.css` `css/series.css` | 共通のスタイル（ライト／ダーク） |
| `vendor/katex/` | 数式の組版（KaTeX、MIT ライセンス） |
| `data/seed.js` | 三重振り子の既定パラメータの最適軌道（初期値） |
| `scripts/` | 三重振り子の初期値を作るスクリプト（下記） |

## 三重振り子の既定の解を作り直す

```sh
cd triple
uv run scripts/ipopt_seed.py   # CasADi + IPOPT で多重スタート → data/ipopt_seed.json（数分）
node scripts/build_seed.mjs    # js/planner.js で解き直して data/seed.js
```
