試すか、使うか：探索と活用

いつものお店に行くか、新しいお店を試すか。わかっている最善を使い続けると、もっと良いものに出会えません。試してばかりでは、良いものを楽しめません。

スロットマシンの問題

これは多腕バンディット問題と呼ばれ、探索と活用のジレンマのいちばん単純な形です。ε の割合でわざとでたらめに選ぶ方法を ε-貪欲法と言います。

楽観的に始める

もうひとつの工夫は、知らないものは良いと思っておくことです。まだ試していない行動の価値を高めに見積もっておくと、試してみてがっかりするまで、次々と新しい行動を試すことになります。デモの台車では、価値の初期値を 0 にしています。報酬は毎歩 −1 なので、0 は「どこからでもすぐゴールに着ける」という楽観的な見積もりです。だから ε = 0 でも、まだ通っていない状態や行動を自然に試します。

デモで「悲観的に始める」（初期値 −200）を選んでやり直すと、学習がいつまでも人の規則に届かなくなります。一度ゴールにたどり着いた道筋を「それなりに良い」と思い込み、もっと良い道を探さなくなるからです（試した例では、最後の 50 回の平均が 200 歩前後のまま）。

制御にとっての探索

本物の機械で「わざとでたらめに動く」のは危険です。ロボットが壊れたり、人にぶつかったりするかもしれません。これが、強化学習を実機にそのまま使いにくい大きな理由のひとつです。実際には、シミュレーションの中で探索させ、学んだものを実機に移す（シム・トゥ・リアル）ことが多く、その「移す」ところがまた難しい問題になっています。
