入力と出力の性格：伝達関数

古典制御は、相手を「入力を入れると出力が出てくる箱」として扱います。箱の中身の細かい仕組みより、入力に対して出力がどう反応するか、その「性格」に注目します。

箱として見る

部屋の温め方を考えるとき、壁の断熱材の厚さや空気の流れを全部計算する必要はありません。「ヒーターを入れると、室温はこう上がっていく」という反応の仕方さえわかれば、ヒーターの入れ方を決められます。

いちばん基本の性格：1 次遅れ

お茶が冷める、お風呂が温まる、コンデンサに電気がたまる。世の中の多くのものがこの形で反応します。これを1 次遅れと呼びます。

伝達関数：性格を式で書く

この性格を、古典制御では次のような式で書きます。

G(s) = K / (T s + 1)

s は「時間で微分する」ことを表す記号だと思ってください。この形を伝達関数と呼びます。伝達関数の便利なところは、箱をつないだときの計算が、ただの掛け算と割り算になることです。

制御器 C と相手 P を掛けた L = CP を一巡伝達関数と呼びます。信号がループを一周したときに何倍になって戻ってくるかを表し、古典制御の主役になります。デモのボード線図とナイキスト線図は、どちらもこの L を描いたものです。

デモの題材の性格

サーボのモーターにトルクを加えると、角度は「加速度 → 速さ → 角度」と 2 回積み重なって変わります。ゆっくりした動きで見ると、性格は 1/(J s²)（J は回りにくさ）です。ただし軸がねじれるので、ある周波数（デモの既定では 15 Hz）で大きく揺れる共振があります。これが 4〜6 ページの主役になります。

もう少し詳しく：ラプラス変換

時間の関数 f(t) をラプラス変換 F(s) = ∫0∞ f(t) e−st dt で移すと、微分 df/dt は s F(s) − f(0) になる。初期値を 0 とすれば微分は s を掛けることに対応し、線形の微分方程式は s の多項式の割り算になる。例：T ẏ + y = K u → (Ts + 1)Y = KU → Y/U = K/(Ts + 1)。

デモの対象（トルクからモーター側の角度まで、粘性摩擦を省く）は

P(s) = (Jl s² + cs + k) / ( s² [ JmJl s² + (Jm + Jl)(cs + k) ] )

分子の根が反共振 ωa = √(k/Jl)、分母の括弧の根が共振 ωr = √(k(1/Jm + 1/Jl))。s² は剛体として回る部分（2 回の積分）。
