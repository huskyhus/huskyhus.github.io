# ch3 第3部 フィードバックの構造

## s01 標準フィードバック系

### ch3/s01/1
<!-- def 定義8 -->
定義8。この図の系を考える。{r|アール} を参照信号、あるいは目標値と呼ぶ。出力が追いかけるべき値である。{e = r − y|イー・イコール・アール・マイナス・ワイ} を偏差、{d|ディー} を外乱と呼ぶ。外乱とは、こちらが選べず、値も知らない入力のことで、振り子なら台車を軽く小突く力がそれに当たる。

### ch3/s01/2
制御器 {C|シー} と制御対象 {P|ピー} を直列につないだ {L = PC|エル・イコール・ピー・シー} を、ループ伝達関数という。そこから {S = 1/(1+L)|エス・イコール、1・プラス・エル・分の1} を感度関数、{T = L/(1+L)|ティー・イコール、1・プラス・エル・分のエル} を相補感度関数と呼ぶ。定義から {S + T = 1|エス・プラス・ティー・イコール・1} である。

### ch3/s01/3
図をそのまま方程式に書けば、{Y = TR + PSD|ワイ・イコール・ティー・アール・プラス・ピー・エス・ディー}、{E = SR − PSD|イー・イコール・エス・アール・マイナス・ピー・エス・ディー} が得られる。工学部で時間をかけるブロック線図の等価変換は、この種の連立一次方程式を絵で解く技術である。ここでは代数で済ませる。

## s02 感度という名前

### ch3/s02/1
{S|エス} を感度関数と呼ぶ理由は、次の計算にある。制御対象が {P|ピー} から少しずれたとき、{T|ティー} の相対的な変化を {P|ピー} の相対的な変化で割ると、ちょうど {S|エス} になる。

### ch3/s02/2
{|S(jω)||エス・ジェイ・オメガの絶対値} が小さい周波数では、モデルの誤差も外乱も、出力にはほとんど現れない。フィードバックを掛ける理由は、この1行に尽きる。

## s03 内部安定

### ch3/s03/1
<!-- def 定義9 -->
定義9。参照信号と外乱の組から、偏差と入力の組への伝達関数は4本ある。その4本がすべて BIBO 安定のとき、閉ループ系は内部安定であるという。

### ch3/s03/2
{P|ピー} と {C|シー} をそれぞれ既約分数で {n_P/d_P|エヌ・ピー・わる・ディー・ピー}、{n_C/d_C|エヌ・シー・わる・ディー・シー} と書くと、内部安定であることは、特性多項式 {d_P d_C + n_P n_C|ディー・ピー・ディー・シー・プラス・エヌ・ピー・エヌ・シー} の根がすべて {ℂ₋|シー・マイナス} にあることと同値になる。この根を閉ループ極と呼ぶ。

### ch3/s03/3
参照信号から出力への {T|ティー} だけを見ても足りない。制御対象の不安定な極を、制御器の零点で打ち消したとする。{T|ティー} の上では極が消えて安定に見えるが、外乱から出力への経路は発散する。第2部の、約分で消える固有値と同じ話である。

## s04 ステップ応答の指標

### ch3/s04/1
<!-- def 定義10 -->
定義10。初期値 0 から、時刻 0 以後ずっと 1 である入力を加えたときの出力を、ステップ応答という。安定な系なら、ステップ応答は定常値 {G(0)|ジー・オブ・ゼロ} に収束する。

### ch3/s04/2
応答の最大値が定常値を超える割合を、行き過ぎ量、あるいはオーバーシュートという。応答が定常値のプラス・マイナス2パーセントの帯に入り、以後そこから出なくなる時刻を整定時間という。帯を5パーセントにとる流儀もあるが、本講義では2パーセントを使う。

### ch3/s04/3
参照信号がステップのとき、時間無限大での偏差の極限を定常偏差という。

## s05 2次系

### ch3/s05/1
図は2次系 {G(s) = ωₙ²/(s² + 2ζωₙs + ωₙ²)|ジー・オブ・エス・イコール、オメガ・エヌ二乗、わる、エス二乗・プラス・2ゼータ・オメガ・エヌ・エス・プラス・オメガ・エヌ二乗} のステップ応答である。{ζ|ゼータ} を減衰係数、{ωₙ|オメガ・エヌ} を固有角周波数と呼ぶ。

### ch3/s05/2
極は {−ζωₙ ± jωₙ√(1−ζ²)|マイナス・ゼータ・オメガ・エヌ、プラス・マイナス・ジェイ・オメガ・エヌ・ルート1マイナス・ゼータ二乗} にある。行き過ぎ量は {exp(−πζ/√(1−ζ²))|イー・のマイナス・パイ・ゼータ・わる・ルート1マイナス・ゼータ二乗・乗} で、{ζ|ゼータ} だけで決まる。整定時間はおおよそ {4/(ζωₙ)|ゼータ・オメガ・エヌ・分の4} である。

### ch3/s05/3
極が虚軸から遠いほど速く落ち着き、実軸から測った角度が大きいほど振動的になる。この見方は、高次の系でも、虚軸にいちばん近い極についておおむね通用する。

## s06 定常偏差と内部モデル原理

### ch3/s06/1
定常偏差は終値定理から一行で出る。閉ループが内部安定なら、ステップの参照信号に対する定常偏差は {S(0) = 1/(1 + L(0))|エス・オブ・ゼロ・イコール、1・プラス・エル・オブ・ゼロ・分の1} である。

### ch3/s06/2
{L|エル} が {s = 0|エス・イコール・ゼロ} に極を持てば、{L(0)|エル・オブ・ゼロ} は無限大で {S(0)|エス・オブ・ゼロ} は 0、偏差は残らない。一般に、消したい信号を生み出すモデルをループの中に入れておけばよい。ステップなら {1/s|エス分の1}、周波数 {ω₀|オメガ・ゼロ} の正弦波なら {1/(s² + ω₀²)|エス二乗・プラス・オメガ・ゼロ二乗・分の1} である。これを内部モデル原理と呼ぶ。

## s07 PID 制御

### ch3/s07/1
<!-- def 定義11 -->
定義11。偏差の現在値、積分、微分の線形結合で入力を作る制御則を、PID 制御という。伝達関数で書けば {C(s) = k_p + k_i/s + k_d s|シー・オブ・エス・イコール、ケー・ピー・プラス、ケー・アイ・わる・エス、プラス、ケー・ディー・エス} である。{k_i = 0|ケー・アイ・イコール・ゼロ} のものを PD 制御と呼ぶ。

### ch3/s07/2
一般に、信号に掛ける倍率をゲインと呼ぶ。{k_p, k_i, k_d|ケー・ピー、ケー・アイ、ケー・ディー} は、それぞれ比例ゲイン、積分ゲイン、微分ゲインである。

### ch3/s07/3
積分の項は、先ほどの内部モデル原理のいちばん簡単な実例で、ステップ状の偏差を残さない。微分の項は減衰を与える。実際の実装では {k_d s|ケー・ディー・エス} をそのまま使わず、高い周波数を切るフィルタを掛ける。

## s08 振り子を PD 制御で立てる

### ch3/s08/1
振り子を PD 制御で立てる。目標は {θ = 0|シータ・イコール・ゼロ} なので参照信号は 0 とする。{P_θ|ピー・シータ} の負の符号を打ち消すため、制御器を {C(s) = −(k_p + k_d s)|シー・オブ・エス・イコール、マイナス、ケー・ピー・プラス・ケー・ディー・エス} と置く。

### ch3/s08/2
閉ループの特性多項式は {s² + bk_d s + (bk_p − p²)|エス二乗・プラス・ビー・ケー・ディー・エス・プラス、ビー・ケー・ピー・マイナス・ピー二乗} である。2次のラウス・フルビッツ条件から、内部安定の必要十分条件は {k_d > 0|ケー・ディーが正} かつ {k_p > p²/b = (M+m)g|ケー・ピーが、エム・プラス・小文字のエム、かけるジーより大きい} になる。

### ch3/s08/3
後のほうの条件は、角度に比例して押す強さが、重力が振り子を倒そうとする強さに勝っている、と読める。数値では {(M+m)g|エム・プラス・小文字のエム、かけるジー} は 10.78 ニュートンである。

### ch3/s08/4
{k_p = 43|ケー・ピー・イコール・43}、{k_d = 4|ケー・ディー・イコール・4} とすると、特性多項式は {s² + 8s + 64.44|エス二乗・プラス・8エス・プラス・64.44} になる。{ωₙ|オメガ・エヌ} はおよそ 8.0、{ζ|ゼータ} はおよそ 0.50 である。先ほどの図の2次系は、ちょうどこの極の配置を持つ。行き過ぎ量は約16パーセントで、0.45秒で最大になり、約1.0秒で2パーセントの帯に収まる。

## s09 根軌跡

### ch3/s09/1
{k_d = 4|ケー・ディー・イコール・4} に固定して、{k_p|ケー・ピー} を 0 から増やしていく。閉ループ極は {s = −4 ± √(37.56 − 2k_p)|エス・イコール、マイナス4、プラス・マイナス、ルート・37.56・マイナス・2ケー・ピー} である。スライダーで {k_p|ケー・ピー} を動かしてみてほしい。

### ch3/s09/2
{k_p|ケー・ピー} が 10.78 より小さい間は正の実根があり、振り子は倒れる。10.78 で根が原点を横切り、18.78 までは負の実根が二つになる。18.78 を超えると、実部がマイナス4の共役な複素根になる。

### ch3/s09/3
このように、ゲイン {k_p|ケー・ピー} を動かしたときの根の軌跡を複素平面に描いたものを、根軌跡という。工学部では作図の規則を教えるが、ここでは、係数が連続に動けば根も連続に動く、という事実の絵だと思えば足りる。

## s10 台車はどうなったか

### ch3/s10/1
一つ問題が残っている。角度は立ったが、台車はどうなったか。この制御器は角度しか見ておらず、{A|エー} の固有値 0 の二つには触れていない。

### ch3/s10/2
元の非線形の運動方程式で確かめる。振り子を 0.2 ラジアン傾けて放すと、角度は 0 に戻るが、台車は毎秒約 0.26 メートルで流れ続け、8秒後には 2.15 メートル先にいる。台車も振り子も同時に止めるには、四つの状態をまとめて扱う必要がある。それは第5部の仕事になる。
