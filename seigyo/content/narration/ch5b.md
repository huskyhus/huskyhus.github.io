# ch5b 第5部（後半） 最適レギュレータ

## s01 どこに置けばよいか

### ch5b/s01/1
ここまでで、固有値をどこにでも置けることは分かった。しかし、どこに置けばよいかはまだ決まっていない。

### ch5b/s01/2
固有値を左へ遠く置くほど、状態は速く 0 に収束する。その代わり入力が大きくなり、測定の雑音にも敏感になる。この兼ね合いを目的関数として書いたのが、次の問題である。

## s02 最適レギュレータ

### ch5b/s02/1
{Q|キュー} を半正定値、{R|アール} を正定値の行列とし、評価関数 {J|ジェイ} を、{zᵀQz + uᵀRu|ゼット転置・キュー・ゼット・プラス・ユー転置・アール・ユー} の 0 から無限大までの積分で定める。第1項は状態のずれへの罰、第2項は入力の大きさへの罰である。

### ch5b/s02/2
定理。{(A, B)|エー・ビー} が可安定で、{(Q^{1/2}, A)|キューの2分の1乗、エー} が可検出だとする。このとき代数リッカチ方程式 {AᵀX + XA − XBR^{−1}BᵀX + Q = 0|エー転置・エックス・プラス・エックス・エー・マイナス、エックス・ビー・アールの逆・ビー転置・エックス、プラス・キュー・イコール・ゼロ} は、{A − BR^{−1}BᵀX|エー・マイナス・ビー・アールの逆・ビー転置・エックス} をフルビッツにする半正定値の解 {X|エックス} を、ただ一つ持つ。

### ch5b/s02/3
{J|ジェイ} を最小にする入力は、状態フィードバック {u = −R^{−1}BᵀXz|ユー・イコール・マイナス・アールの逆・ビー転置・エックス・ゼット} で与えられ、最小値は {z(0)ᵀXz(0)|ゼット・ゼロ転置・エックス・ゼット・ゼロ} である。この制御則を最適レギュレータ、英語の頭文字で LQR と呼ぶ。

## s03 平方完成による証明

### ch5b/s03/1
最適性のほうは平方完成で示せる。任意の安定化する入力について、{zᵀXz|ゼット転置・エックス・ゼット} の時間微分を計算し、リッカチ方程式を使って整理する。

### ch5b/s03/2
すると被積分関数は、{zᵀXz|ゼット転置・エックス・ゼット} の時間微分にマイナスを付けたものと、{u + R^{−1}BᵀXz|ユー・プラス・アールの逆・ビー転置・エックス・ゼット} についての {R|アール} の二次形式との和になる。

### ch5b/s03/3
積分すれば、{J|ジェイ} は {z(0)ᵀXz(0)|ゼット・ゼロ転置・エックス・ゼット・ゼロ} に、非負の項を足したものになる。その非負の項を 0 にする入力が、先の状態フィードバックである。解の存在と一意性は、ハミルトン行列の安定な不変部分空間を使う話になるので、ここでは主張だけにとどめる。

## s04 振り子の LQR

### ch5b/s04/1
振り子で {Q = diag(10, 1, 100, 1)|キュー・イコール、対角に、10、1、100、1}、{R = 1|アール・イコール・1} とする。{Q|キュー} の3番目の成分を大きくしたのは、台車のずれよりも、角度のずれを重く罰したいからである。

### ch5b/s04/2
リッカチ方程式を解くと、{K ≈ (−3.16, −4.43, −39.58, −8.48)|ケーは、およそ、マイナス3.16、マイナス4.43、マイナス39.58、マイナス8.48} になる。閉ループの固有値は、{−5.17 ± 1.72j|マイナス5.17、プラス・マイナス、1.72ジェイ} と {−1.10 ± 0.94j|マイナス1.10、プラス・マイナス、0.94ジェイ} である。

### ch5b/s04/3
極配置で選んだ {K|ケー} と比べると、角度に掛かる係数は 49 から 40 へ小さくなっている。罰の重みから、固有値の置き場所が自動的に決まった。

## s05 非線形の振り子に掛ける

### ch5b/s05/1
この {K|ケー} を、線形化していない元の運動方程式に掛ける。振り子を右に 0.2 ラジアン傾けて放したところから始める。

### ch5b/s05/2
台車はまず右へ走り、0.9秒の時点で約 0.35 メートル先に達して、振り子の真下に回り込む。そのあと原点へ戻ってくる。入力の大きさの最大値は約 7.9 ニュートンで、約4秒でほぼ原点に落ち着く。

### ch5b/s05/3
上は第3部の PD 制御、下は LQR である。同じ初期値から始めても、PD 制御では台車が流れ続け、LQR では戻ってくる。台車の位置と速度を入力に戻したことの差が、ここに出ている。

## s06 LQR の安定余裕

### ch5b/s06/1
1入力の LQR には、ロバスト性のおまけが付く。入力のところでループを切った {L(s) = K(sI − A)^{−1}B|エル・オブ・エス・イコール、ケー、エス・アイ・マイナス・エーの逆行列、ビー} について、すべての {ω|オメガ} で {|1 + L(jω)| ≥ 1|1・プラス・エル・ジェイ・オメガの絶対値は1以上} が成り立つ。カルマンの不等式と呼ばれる。

### ch5b/s06/2
ナイキスト線図で言えば、曲線は {−1|マイナス1} を中心とする半径1の円の中に入らない。ここから、位相余裕は60度以上、ゲインは2分の1倍から無限大倍まで変えても安定が保たれる。

### ch5b/s06/3
ただし、オブザーバを挟むと、この保証は消える。ガウス雑音のもとで最適なオブザーバゲインを双対なリッカチ方程式で求めたものをカルマンフィルタと呼び、それと LQR を組んだものを LQG 制御器と呼ぶ。この組み合わせでも、安定余裕はいくらでも小さくなりうる。カルマンフィルタと LQG はどちらも本講義の範囲外で、ここでは名前だけを挙げる。
