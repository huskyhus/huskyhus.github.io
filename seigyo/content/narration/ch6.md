# ch6 第6部 ロバスト性と根本的な限界、まとめ

## s01 H∞ ノルムとロバスト安定

### ch6/s01/1
<!-- def 定義19 -->
定義19。極がすべて {ℂ₋|シー・マイナス} にあるプロパーな {G|ジー} について、{|G(jω)||ジー・ジェイ・オメガの絶対値} の {ω|オメガ} についての上限を {‖G‖∞|ジー・のエイチ・インフィニティ・ノルム} と書き、H∞ ノルムと呼ぶ。周波数ごとのゲインの最大値である。

### ch6/s01/2
制御対象の本当の伝達関数は分からないが、{P(1 + WΔ)|ピー、かける、1・プラス・ダブリュー・デルタ} の形のどれかだとは分かっているとする。{Δ|デルタ} は安定で、H∞ ノルムが1以下の任意の伝達関数である。{W|ダブリュー} は、各周波数でモデルが何割ずれうるかを表す重みである。

### ch6/s01/3
この集合のすべての元に対して閉ループが内部安定なとき、制御器はロバスト安定化するという。ナイキストの定理から、その必要十分条件は {‖WT‖∞ < 1|ダブリュー・ティーの、エイチ・インフィニティ・ノルムが1より小さい} である。曲線の各点を、ずれの分だけ動かしても {−1|マイナス1} を跨がない、という条件を書き下したものにすぎない。

## s02 ボードの感度積分

### ch6/s02/1
定理。{L|エル} の分母と分子の次数の差を、相対次数と呼ぶ。相対次数が2以上で、閉ループが内部安定だとする。{L|エル} の開右半平面の極を {p₁|ピー・ワン} から {p_k|ピー・ケー} とすると、{log|S(jω)||ログ、エス・ジェイ・オメガの絶対値} を 0 から無限大まで積分したものは、{π|パイ} かける、極の実部の和に等しい。

### ch6/s02/2
右辺は 0 以上である。だから、ある周波数の帯で {|S||エスの絶対値} を1より小さくして外乱を抑えれば、必ずどこか別の周波数で {|S||エスの絶対値} が1を超え、外乱が増幅される。一箇所を踏み込めば別の場所が盛り上がる、という比喩で知られている。

## s03 証明の方針

### ch6/s03/1
証明は、{log S|ログ・エス} を右半平面の大きな半円で囲み、コーシーの積分定理を使う。相対次数が2以上なので、大きな半円の上の寄与は消える。

### ch6/s03/2
困るのは、{L|エル} の不安定な極が {S|エス} の零点になり、そこで {log S|ログ・エス} が特異になることである。その零点をブラシュケ積で外してから計算すると、外した分が右辺の {π|パイ} かける実部の和として現れる。

## s04 振り子の感度積分

### ch6/s04/1
振り子では、不安定な極は {p|ピー} の一つなので、右辺は {πp|パイ・ピー}、およそ 14.6 である。

### ch6/s04/2
第3部の PD 制御の {L|エル} は相対次数が1なので、この形の定理はそのままでは当てはまらない。しかし実際には微分の項にフィルタを掛けるので、相対次数は2以上になる。

### ch6/s04/3
{p² = (M+m)g/(Mℓ)|ピー二乗・イコール、エム・プラス・小文字のエム、かけるジー、わる、エム・エル} なので、棒が短いほど右辺は大きく、払うべき盛り上がりも大きい。棒の長さを 0.5 メートルから 0.25 メートルにすると、{p|ピー} は約 6.57 に、右辺は約 20.6 に増える。短い棒のほうが手のひらの上で立てにくい、という経験と合っている。

## s05 非最小位相

### ch6/s05/1
<!-- def 定義20 -->
定義20。開右半平面に零点を持つ伝達関数を、非最小位相であるという。

### ch6/s05/2
制御対象がそういう零点 {z|ゼット} を持つと、内部安定性から {S(z) = 1|エス・オブ・ゼット・イコール・1} は避けられない。最大値原理により、{‖S‖∞|エスのエイチ・インフィニティ・ノルム} は1以上になる。

### ch6/s05/3
さらに右半平面の極 {p|ピー} もあれば、{‖S‖∞ ≥ |(z + p)/(z − p)||エスのエイチ・インフィニティ・ノルムは、ゼット・プラス・ピー、わる、ゼット・マイナス・ピー、の絶対値・以上} という下界が得られる。零点と極が近いほど、この下界は大きくなる。

## s06 台車の位置だけで立てられるか

### ch6/s06/1
第2部で求めた {P_x|ピー・エックス} は、右半平面に零点 {z ≈ 4.43|ゼット、およそ4.43} と極 {p ≈ 4.64|ピー、およそ4.64} を持つ。二つはとても近い。

### ch6/s06/2
台車の位置 {x|エックス} だけを測って振り子を立てようとすると、どんな制御器を使っても {‖S‖∞|エスのエイチ・インフィニティ・ノルム} は約42以上になる。ある周波数の外乱が40倍以上に増幅されるのだから、実用上は立たないと考えてよい。

### ch6/s06/3
第5部では、{y = x|ワイ・イコール・エックス} で可観測だと確かめた。可観測であることと、実際に扱えることは別の問題である。角度のセンサを足して出力を二つにすれば、この壁は大きく下がる。

## s07 まとめ

### ch6/s07/1
第1部の一文に戻る。制御とは、外から加える量を選び、装置の振る舞いを望みの形にすることだった。各部は、この一文の語を一つずつ精密にしてきた。

### ch6/s07/2
第1部は「外から加える量」と「装置」を、入力と系にした。第2部は「振る舞い」を固有値と極にした。第3部と第4部は「望みの形」を、感度関数と安定余裕にした。第5部は「選ぶ」ことを、可制御性と最適化にした。

### ch6/s07/3
第6部は、その望みの形には、制御対象ごとに越えられない上限があることを示した。上限を決めているのは、右半平面にある極と零点の位置である。
