# ch4 第4部 周波数応答とナイキストの安定判別

## s01 周波数応答

### ch4/s01/1
<!-- def 定義12 -->
定義12。{G|ジー} を BIBO 安定な伝達関数とする。入力に正弦波 {sin ωt|サイン・オメガ・ティー} を入れると、過渡的な項が消えたあとの出力は {|G(jω)| sin(ωt + arg G(jω))|ジー・ジェイ・オメガの絶対値、かける、サイン、オメガ・ティー・プラス、ジー・ジェイ・オメガの偏角} になる。

### ch4/s01/2
{ω ≥ 0|オメガ・ゼロ以上} の関数 {G(jω)|ジー・オブ・ジェイ・オメガ} を周波数応答と呼ぶ。偏角 {arg G(jω)|アーグ・ジー・ジェイ・オメガ} を位相と呼ぶ。絶対値 {|G(jω)||ジー・ジェイ・オメガの絶対値} は正弦波の振幅が何倍になるかを表すので、定義11の意味で、周波数 {ω|オメガ} でのゲインと呼ぶ。

### ch4/s01/3
横軸に {log ω|ログ・オメガ}、縦軸にゲインの {20 log₁₀|20・ログ・10} をとった図と、位相をとった図の2枚組をボード線図という。縦軸の単位はデシベルである。対数をとるのは、直列につないだ要素の積が、グラフの上では和になるからである。

## s02 不安定な系の周波数応答

### ch4/s02/1
{G|ジー} が不安定なら、正弦波への応答という解釈は成り立たない。それでも {G(jω)|ジー・オブ・ジェイ・オメガ} という複素数の値そのものは定義できる。これから使うのはこの値のほうである。

### ch4/s02/2
第3部の振り子の PD 制御で、ループ伝達関数は {L(s) = 2(43 + 4s)/(s² − 21.56)|エル・オブ・エス・イコール、2かける、43・プラス・4エス、わる、エス二乗・マイナス・21.56} である。そのボード線図がこれである。{ω|オメガ} が 0.1 から 316 までを描いている。低い周波数でゲインは約12デシベル、{ω|オメガ} がおよそ 9.7 で 0 デシベルを横切る。

## s03 ナイキスト線図

### ch4/s03/1
<!-- def 定義13 -->
定義13。虚軸を下から上へ、つまり {ω|オメガ} をマイナス無限大からプラス無限大まで動かしたときの {L(jω)|エル・オブ・ジェイ・オメガ} の像を、向きのついた閉曲線として複素平面に描く。これをナイキスト線図という。

### ch4/s03/2
{L|エル} が虚軸の上に極を持つときは、その極を右側の小さな半円で避けて通る。{ω|オメガ} が負の半分は、正の半分の複素共役なので、実軸について折り返せば得られる。

## s04 ナイキストの定理

### ch4/s04/1
定理。{L = PC|エル・イコール・ピー・シー} をプロパーな有理関数とし、{P|ピー} と {C|シー} の間で不安定な極と零点の約分は起きていないとする。{L|エル} の開右半平面にある極の個数を、重複度を込めて {P|大文字のピー} と書く。

### ch4/s04/2
ナイキスト線図が {−1|マイナス1} の点を反時計回りに回る回数を {N|エヌ} とする。このとき、閉ループ系が内部安定であることと、{N = P|エヌ・イコール・ピー} であることは同値である。

## s05 証明

### ch4/s05/1
閉ループ極は {1 + L|1・プラス・エル} の零点である。そのうち開右半平面にあるものの個数を {Z|ゼット} とする。{1 + L|1・プラス・エル} の極は {L|エル} の極と同じである。

### ch4/s05/2
虚軸と、半径 {R|アール} の右半円からなる閉曲線を、時計回りにたどる。偏角原理により、{1 + L|1・プラス・エル} の像は原点を時計回りに {Z − P|ゼット・マイナス・ピー} 回まわる。

### ch4/s05/3
{L|エル} はプロパーなので、{R|アール} を無限大にすると半円の像は1点に潰れる。残るのは虚軸の像、すなわちナイキスト線図である。{1 + L|1・プラス・エル} が原点を回ることは、{L|エル} が {−1|マイナス1} を回ることと同じである。向きを反時計回りに直せば {N = P − Z|エヌ・イコール・ピー・マイナス・ゼット}。{Z = 0|ゼット・イコール・ゼロ} と {N = P|エヌ・イコール・ピー} は同値である。証明終わり。

## s06 振り子に当てる

### ch4/s06/1
振り子の {L|エル} では、不安定な極は {s = +p|エス・イコール・プラス・ピー} の一つだけなので、{P = 1|ピー・イコール・1} である。

### ch4/s06/2
ナイキスト線図を見る。曲線は原点から上半平面を通って、{L(0)|エル・オブ・ゼロ}、およそ {−3.99|マイナス3.99} に至り、下半平面を通って原点に戻る。{−1|マイナス1} はその内側にあり、反時計回りに1周されている。{N = 1|エヌ・イコール・1} で {P|ピー} と等しいので、閉ループは安定である。

### ch4/s06/3
{k_d = 0|ケー・ディー・イコール・ゼロ}、つまり {k_p|ケー・ピー} の項だけの PD 制御にすると、{L(jω)|エル・オブ・ジェイ・オメガ} は実数になり、曲線は実軸上の線分に潰れる。線分は何も回れないので {N = 0|エヌ・イコール・ゼロ}。{k_p|ケー・ピー} の項だけでは振り子を立てられないことが、第3部の代数とは別の道筋で分かる。

## s07 安定余裕

### ch4/s07/1
<!-- def 定義14 -->
定義14。{|L(jω)| = 1|エル・ジェイ・オメガの絶対値・イコール・1} となる周波数 {ω_c|オメガ・シー} をゲイン交差周波数という。そこでの位相に 180度を足したものを位相余裕という。

### ch4/s07/2
ループのゲインを何倍まで変えると、ナイキスト線図が {−1|マイナス1} を通ってしまうか。その倍率をゲイン余裕という。どちらも、モデルと実物のずれがどこまで許されるかの目安である。

## s08 振り子の安定余裕

### ch4/s08/1
振り子では、ゲイン交差周波数はおよそ毎秒 9.7 ラジアン、位相余裕は約42度である。{ω|オメガ} のスライダーを動かすと、ナイキスト線図の上の点と、ボード線図の上の縦線が一緒に動く。

### ch4/s08/2
ゲイン余裕のほうは少し変わっている。曲線が負の実軸と交わるのは、{ω = 0|オメガ・イコール・ゼロ} の {−3.99|マイナス3.99} だけである。だからゲインを上げても不安定にはならない。代わりに、{k_p|ケー・ピー} と {k_d|ケー・ディー} を同じ倍率で 0.25倍、約マイナス12デシベルより下げると、曲線が {−1|マイナス1} を回らなくなり、振り子は倒れる。

### ch4/s08/3
制御を弱めれば安定の側に寄る、という直観は、制御対象そのものが不安定なときには成り立たない。これは第3部の条件 {k_p > 10.78|ケー・ピーが10.78より大きい} の言い換えになっている。43 の 0.25倍は、ほぼ 10.78 である。

## s09 ループ整形

### ch4/s09/1
ここから設計の考え方が出てくる。低い周波数では {|L||エルの絶対値} を大きくして {|S||エスの絶対値} を小さくしたい。参照信号に追従させ、外乱を抑えるためである。

### ch4/s09/2
高い周波数では、センサの雑音や、モデルに入れていない速い振動が効いてくるので、{|L||エルの絶対値} を小さくしたい。その間を、十分な位相余裕を保ったまま渡るように {C|シー} を選ぶことを、ループ整形という。

### ch4/s09/3
交差周波数のあたりで位相を進める要素 {(1 + s/a)/(1 + s/b)|1・プラス・エス・わる・エー、わる、1・プラス・エス・わる・ビー}、ただし {a < b|エーはビーより小さい}、を位相進み補償と呼ぶ。低い周波数のゲインだけを持ち上げる要素を位相遅れ補償と呼ぶ。

## s10 ゲインと位相は独立に選べない

### ch4/s10/1
この「渡る」ことには制約がある。右半平面に極も零点も持たない安定な {L|エル} では、位相はゲインの曲線から一意に決まる。実部と虚部がヒルベルト変換で結ばれているのと同じ構造である。

### ch4/s10/2
{ω|オメガ} が10倍になるごとにゲインが20デシベルの割合で下がる区間では、位相はおよそマイナス90度になる。ゲインを急に落とすと位相がマイナス180度に近づき、余裕がなくなる。だから交差周波数の前後では、ゲインを緩やかにしか下げられない。
