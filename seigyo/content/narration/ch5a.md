# ch5a 第5部（前半） 状態空間での設計

## s01 状態フィードバック

### ch5a/s01/1
<!-- def 定義15 -->
定義15。行列 {K|ケー} を使って {u = −Kz|ユー・イコール・マイナス・ケー・ゼット} とする制御則を、状態フィードバックという。閉ループ系は {ż = (A − BK)z|ゼット・ドット・イコール、エー・マイナス・ビー・ケー、ゼット} になる。

### ch5a/s01/2
第3部の PD 制御は角度と角速度しか使わなかった。状態フィードバックは、台車の位置と速度も含めた四つすべてを使う。状態がすべて測れるという仮定は、あとで、出力から状態を推定することで外す。

## s02 可制御性

### ch5a/s02/1
<!-- def 定義16 -->
定義16。どんな2点 {z₀|ゼット・ゼロ}、{z₁|ゼット・ワン} と、どんな正の時間 {T|ティー} に対しても、区間 0 から {T|ティー} の上の入力をうまく選んで、{z₀|ゼット・ゼロ} から {z₁|ゼット・ワン} へ移せるとき、{(A, B)|エー・ビー} は可制御であるという。

### ch5a/s02/2
{B, AB, …, A^{n−1}B|ビー、エー・ビー、から、エーのエヌ・マイナス1乗・ビー} を横に並べた行列を、可制御性行列と呼ぶ。

## s03 カルマンの階数条件

### ch5a/s03/1
定理。{(A, B)|エー・ビー} が可制御であることと、可制御性行列の階数が {n|エヌ} であることは同値である。

### ch5a/s03/2
証明の骨格を示す。時刻 {T|ティー} に原点から届く点全体は、入力から状態への線形写像の像である。その直交補空間にあるベクトル {v|ブイ} は、すべての時刻で {vᵀe^{At}B = 0|ブイ・転置、イー・のエー・ティー乗、ビー・イコール・ゼロ} をみたす。

### ch5a/s03/3
時刻 0 で微分を繰り返すと、すべての {k|ケー} で {vᵀA^kB = 0|ブイ・転置・エーのケー乗・ビー・イコール・ゼロ} が出る。逆向きはテイラー展開から従う。ケイリー・ハミルトンの定理により、{k|ケー} は {n − 1|エヌ・マイナス1} まで調べれば足りる。証明終わり。

## s04 PBH 判定法と可安定

### ch5a/s04/1
同じことを固有値ごとに言い換えたのが、PBH 判定法である。すべての複素数 {λ|ラムダ} で {[λI − A, B]|ラムダ・アイ・マイナス・エー、ビー} の階数が {n|エヌ} なら可制御である。階数が落ちる {λ|ラムダ} が、入力から届かない固有値である。

### ch5a/s04/2
入力から届かない固有値がすべて {ℂ₋|シー・マイナス} にあるとき、{(A, B)|エー・ビー} は可安定であるという。届かない部分は放っておいても減衰するので、安定化には差し支えない。

## s05 極配置

### ch5a/s05/1
定理。1入力系について、{(A, B)|エー・ビー} が可制御であることと、次のことは同値である。どんな {n|エヌ} 次の実モニック多項式 {χ|カイ} に対しても、{det(sI − A + BK) = χ(s)|デターミナント、エス・アイ・マイナス・エー・プラス・ビー・ケー、イコール・カイ・オブ・エス} となる {K|ケー} が存在する。

### ch5a/s05/2
証明は座標変換で済む。{(A, B)|エー・ビー} を可制御正準形に移すと、{A|エー} は同伴行列、{B|ビー} は最後の単位ベクトルになる。この形では {BK|ビー・ケー} は {A|エー} の最後の行だけを書き換える。最後の行は特性多項式の係数そのものなので、係数を好きに選べる。

### ch5a/s05/3
逆向きは、入力から届かない固有値が、{K|ケー} をどう選んでも動かないことから従う。

## s06 振り子の極配置

### ch5a/s06/1
振り子で確かめる。第1部の {A|エー} と {B|ビー} から可制御性行列を作ると、行列式の絶対値は {g²/(M⁴ℓ⁴)|ジー二乗、わる、エムの4乗・エルの4乗} で、0 ではない。数値では 1536.64 である。振り子は可制御である。

### ch5a/s06/2
したがって、四つの固有値をたとえばマイナス2、マイナス3、マイナス4、マイナス5に置く {K|ケー} が、ただ一つ存在する。計算すると {K ≈ (−6.12, −7.86, −49.34, −10.93)|ケーは、およそ、マイナス6.12、マイナス7.86、マイナス49.34、マイナス10.93} になる。

### ch5a/s06/3
最初の二つの成分が、台車の位置と速度に掛かる係数である。第3部の PD 制御に欠けていた台車の情報が、ここで初めて入力に戻される。

## s07 可観測性

### ch5a/s07/1
<!-- def 定義17 -->
定義17。区間 0 から {T|ティー} で入力と出力を観測すれば、初期状態 {z(0)|ゼット・ゼロ} がただ一つに定まるとき、{(C, A)|シー・エー} は可観測であるという。

### ch5a/s07/2
先の定理を {(Aᵀ, Cᵀ)|エー転置、シー転置} に当てはめると、可観測であることは、{C, CA, …, CA^{n−1}|シー、シー・エー、から、シー・エーのエヌ・マイナス1乗} を縦に並べた可観測性行列の階数が {n|エヌ} であることと同値になる。可制御性と可観測性は、転置で入れ替わる双対な概念である。証明を繰り返す必要はない。

### ch5a/s07/3
出力から見えない固有値がすべて {ℂ₋|シー・マイナス} にあるとき、{(C, A)|シー・エー} は可検出であるという。

## s08 振り子は何を測れば見えるか

### ch5a/s08/1
振り子で、台車の位置 {x|エックス} だけを測るとする。{C = (1, 0, 0, 0)|シー・イコール、1、0、0、0} で、可観測性行列の階数は4、可観測である。

### ch5a/s08/2
角度 {θ|シータ} だけを測る {C = (0, 0, 1, 0)|シー・イコール、0、0、1、0} では、階数は2しかない。角度をいくら見ても、台車がどこにいるかは分からない。第2部で {P_θ|ピー・シータ} から固有値 0 が消えていたのは、まさにこのことだった。

## s09 オブザーバ

### ch5a/s09/1
<!-- def 定義18 -->
定義18。推定値 {ẑ|ゼット・ハット} を、微分方程式 {ẑ̇ = Aẑ + Bu + H(y − Cẑ)|ゼット・ハット・ドット・イコール、エー・ゼット・ハット・プラス・ビー・ユー・プラス・エイチ、ワイ・マイナス・シー・ゼット・ハット} で作る系を、オブザーバという。{H|エイチ} は設計者が選ぶ行列で、オブザーバゲインと呼ぶ。

### ch5a/s09/2
最後の項は、実際の出力と、推定値から予想される出力との食い違いで、推定値を補正している。誤差 {ε = z − ẑ|イプシロン・イコール・ゼット・マイナス・ゼット・ハット} は {ε̇ = (A − HC)ε|イプシロン・ドット・イコール、エー・マイナス・エイチ・シー、イプシロン} に従う。

### ch5a/s09/3
{A − HC|エー・マイナス・エイチ・シー} の固有値は、双対性により、{(C, A)|シー・エー} が可観測なら自由に置ける。転置すれば {Aᵀ − CᵀHᵀ|エー転置・マイナス・シー転置・エイチ転置} で、極配置の問題そのものになるからである。

## s10 分離定理

### ch5a/s10/1
定理。状態の代わりに推定値を使って {u = −Kẑ|ユー・イコール・マイナス・ケー・ゼット・ハット} とすると、閉ループの固有値は、{A − BK|エー・マイナス・ビー・ケー} の固有値と {A − HC|エー・マイナス・エイチ・シー} の固有値を合わせたものになる。

### ch5a/s10/2
状態 {z|ゼット} と誤差 {ε|イプシロン} を座標にとると、係数行列がブロック上三角になるので、証明は1行で終わる。工学上の意味は、制御器と推定器を別々に設計してよい、ということである。
