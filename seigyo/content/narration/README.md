# ナレーション原稿の書式

音声合成（VOICEVOX のずんだもんなど）で後から読み上げるための原稿。章ごとに1ファイル（`ch1.md`, `ch2.md`, `ch3.md`, `ch4.md`, `ch5a.md`, `ch5b.md`, `ch6.md`）。

## 構造

```markdown
# ch1 第1部 制御の問題と倒立振り子

## s01 制御とは

### ch1/s01/1
（このステップで読む文）

### ch1/s01/2
<!-- def 定義1 -->
（定義1を述べるステップには、この印を付ける）
```

- `##` が場面、`###` がステップ。`###` の見出しはステップ ID（章/場面/ステップ）そのもので、場面データ（`content/scenes/`）からこの ID で引く。
- 1ステップ = 1音声ファイル。音声は `audio/<章>/<場面>-<ステップ>.wav`（例：`audio/ch1/s03-2.wav`）に置く。
- 定義を述べるステップには `<!-- def 定義N -->` を付ける。`scripts/check_terms.py` が用語の出る順をこの印で検査する。

## 読みの指定

数式や記号は、画面の字幕と音声で読み方が違う。`{表記|よみ}` と書くと、字幕には表記、音声合成にはよみを渡す。

```
{ż = f(z, u)|ゼット・ドット・イコール・エフ・オブ・ゼット・ユー}
{p ≈ 4.64|ピー、およそ4.64}
```

表記とよみは最後の `|` で分けるので、表記に絶対値 `{|S||エスの絶対値}` を書ける。表記の中の波括弧は対応を数えるので、`{e^{pt}|イー・のピー・ティー乗}` も書ける。字幕では `^{pt}` や `_{n}` を上付き・下付き文字（eᵖᵗ）に直す（`scripts/ruby.py`）。よみには `|` と波括弧を書かない。

よみはカタカナで書く。数字はそのまま書いてよい（合成器が読める）。ギリシャ文字は θ = シータ、ω = オメガ、ζ = ゼータ、ξ = グザイ と読む。

## 文体

- README §9 に従い「である」調で書く。キャラクターの口調（「〜なのだ」など）に変えるときは、原稿を変換するスクリプトで行い、この原稿は書き換えない。
- README §5 の用語の順序はナレーションにも当てはまる。
- 1ステップは声に出して 20〜60 秒程度に収める。
