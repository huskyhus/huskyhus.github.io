# ch1 第1部 制御の問題と倒立振り子

## s01 制御とは

### ch1/s01/1
これから105分かけて、制御工学の全体を一通り見ていく。題材は最初から最後まで一つで、台車の上に立てた振り子である。新しい道具が出てきたら、まずこの振り子に当て、それから一般の形に書き直す。

### ch1/s01/2
制御とは、外から加える量を時間の関数として選び、ある装置の振る舞いを望みの形にすることである。最初の10分で、この一文に出てくる語を数式に置き換える。

## s02 系、状態、入力、出力

### ch1/s02/1
<!-- def 定義1 -->
定義1。本講義で系というのは、二つのものの組のことである。一つは常微分方程式 {ż = f(z, u)|ゼット・ドット・イコール・エフ・オブ・ゼット・ユー}、もう一つは写像 {y = h(z, u)|ワイ・イコール・エイチ・オブ・ゼット・ユー} である。

### ch1/s02/2
{z|ゼット} は {n|エヌ} 次元の実ベクトルで、これを状態と呼ぶ。{u|ユー} を入力、{y|ワイ} を出力と呼ぶ。入力はこちらが選べる量で、出力はセンサで測れる量である。

### ch1/s02/3
制御したい系を、制御対象、あるいはプラントと呼ぶ。{f|エフ} が {C¹|シー・ワン} 級で、入力が区分連続なら、初期値と入力を決めれば解は局所的にただ一つに決まる。この先、解の存在で悩むことはない。

## s03 開ループと閉ループ

### ch1/s03/1
<!-- def 定義2 -->
定義2。入力を時刻の既知の関数として前もって決めてしまうやり方を、開ループ制御、あるいはフィードフォワードという。

### ch1/s03/2
これに対して、出力の観測値を見て入力を決めるやり方をフィードバック制御という。たとえば {u = k(y)|ユー・イコール・ケー・オブ・ワイ} とする。もっと一般には、別の微分方程式を間に挟んで {y|ワイ} から {u|ユー} を作ってもよい。こうしてできる、外からの入力を持たない系を閉ループ系と呼ぶ。

### ch1/s03/3
{y|ワイ} から {u|ユー} を作る規則を制御則といい、それを実際に組み込んだものを制御器、あるいはコントローラという。

## s04 台車型倒立振り子

### ch1/s04/1
振り子の設定はこの図のとおりである。質量 {M|エム} の台車が、水平な直線の上を摩擦なしに動く。その上に、長さ {ℓ|エル} の質量のない棒と、先端の質点 {m|小文字のエム} からなる振り子が、回転自在についている。台車を押す力が入力 {u|ユー} である。

### ch1/s04/2
台車の位置を {x|エックス}、振り子の角度を {θ|シータ} とする。{θ|シータ} は鉛直上向きから測る。すると質点の位置は {(x + ℓ sin θ, ℓ cos θ)|エックス・プラス・エル・サイン・シータ、エル・コサイン・シータ} になる。

### ch1/s04/3
運動エネルギーと位置エネルギーを書いてラグランジュ方程式を立てると、この2本の式が出る。1本目は台車の運動、2本目は振り子の回転を表す。どちらも {θ|シータ} について非線形である。

## s05 平衡点と線形化

### ch1/s05/1
<!-- def 定義3 -->
定義3。{f(zₑ, uₑ) = 0|エフ・オブ・ゼット・イー、ユー・イー・イコール・ゼロ} をみたす組を平衡点という。そこに置けば、ずっとそこに留まる点である。

### ch1/s05/2
平衡点で {f|エフ} と {h|エイチ} のヤコビ行列をとり、{A, B, C, D|エー、ビー、シー、ディー} とおく。平衡点からのずれ {ξ|グザイ} と {v|ブイ} について書いた1次の系、{ξ̇ = Aξ + Bv|グザイ・ドット・イコール・エー・グザイ・プラス・ビー・ブイ} を線形化系と呼ぶ。

### ch1/s05/3
以下では記号を節約して、ずれのほうをあらためて {z|ゼット} と {u|ユー} と書く。

## s06 振り子の線形化

### ch1/s06/1
振り子では、台車が原点に止まり、棒がまっすぐ上を向いて静止している状態、つまり {z = 0|ゼット・イコール・ゼロ}、{u = 0|ユー・イコール・ゼロ} が平衡点である。状態は台車の位置と速度、振り子の角度と角速度を並べた4次元のベクトルにとる。

### ch1/s06/2
{sin θ ≈ θ|サイン・シータをシータ}、{cos θ ≈ 1|コサイン・シータを1} で置き換え、2本の運動方程式を加速度について解くと、線形化系の行列 {A|エー} と {B|ビー} はこの形になる。

## s07 なぜ倒れるか

### ch1/s07/1
{A|エー} の特性多項式は {λ²(λ² − p²)|ラムダ二乗かける、ラムダ二乗マイナス・ピー二乗} である。ここで {p² = (M+m)g/(Mℓ)|ピー二乗は、エム・プラス・小文字のエム、かけるジー、わる、エム・エル}。固有値は 0 が二つと、{±p|プラス・マイナス・ピー} である。

### ch1/s07/2
固有値 {+p|プラス・ピー} があるので、平衡点からのごく小さなずれも {e^{pt}|イー・のピー・ティー乗} の速さで大きくなる。振り子が倒れるということの数学的な中身はこれである。

### ch1/s07/3
数値を入れる。台車 1 キログラム、先端 0.1 キログラム、棒の長さ 0.5 メートル、重力加速度 9.8 とすると、{p²|ピー二乗} は 21.56、{p|ピー} はおよそ 4.64 になる。ずれは約 0.22 秒ごとに {e|イー} 倍になる。この値は、この先ずっと使い続ける。
