# ch2 第2部 線形系の解、安定性、伝達関数

## s01 線形系の解

### ch2/s01/1
第1部で得た線形化系を、一般の形 {ż = Az + Bu|ゼット・ドット・イコール・エー・ゼット・プラス・ビー・ユー}、{y = Cz + Du|ワイ・イコール・シー・ゼット・プラス・ディー・ユー} で考える。この解は定数変化法でそのまま書ける。

### ch2/s01/2
解は二つの項の和である。第1項 {e^{At} z(0)|イー・のエー・ティー乗、かける、ゼット・ゼロ} は初期値が時間とともにどう運ばれるかを表し、第2項の積分は、それまでに加えた入力の影響を足し合わせたものである。行列の指数関数の振る舞いは、{A|エー} のジョルダン標準形を見ればすべて分かる。

## s02 安定性

### ch2/s02/1
<!-- def 定義4 -->
定義4。自律系 {ż = f(z)|ゼット・ドット・イコール・エフ・オブ・ゼット} で、原点が平衡点だとする。どんな {ε|イプシロン} に対しても {δ|デルタ} がとれて、原点から {δ|デルタ} 以内で出発すれば、その後ずっと原点から {ε|イプシロン} 以内に留まるとき、原点はリアプノフ安定であるという。

### ch2/s02/2
さらに、原点の近くから出た解が時間無限大で原点に収束するとき、漸近安定という。工学で単に安定と言えば、たいていはこの漸近安定のことである。

### ch2/s02/3
固有値がすべて開左半平面 {ℂ₋|シー・マイナス} に入る行列を、フルビッツ行列、あるいは安定行列と呼ぶ。

## s03 固有値で安定性が決まる

### ch2/s03/1
命題1。{ż = Az|ゼット・ドット・イコール・エー・ゼット} の原点が漸近安定であることと、{A|エー} がフルビッツであることは同値である。証明はジョルダン標準形から直ちに出る。

### ch2/s03/2
非線形系についても、線形化から言えることがある。平衡点での線形化 {A|エー} がフルビッツなら、その平衡点は漸近安定である。{A|エー} が実部正の固有値を一つでも持てば、不安定である。リアプノフの間接法と呼ばれる結果である。

### ch2/s03/3
振り子の {A|エー} の固有値をもう一度見る。0 が二つと、{±4.64|プラス・マイナス 4.64}。{+4.64|プラス 4.64} が右半平面にあるので、命題1の後半から、線形化していない元の振り子も不安定だと分かる。第1部の「倒れる」は、近似の中だけの話ではなかった。

## s04 ラプラス変換

### ch2/s04/1
<!-- def 定義5 -->
定義5。区間 0 から無限大で局所可積分な関数 {f|エフ} が、ある定数について {|f(t)| ≤ Ke^{at}|エフの絶対値は、ケー・かける・イー・のエー・ティー乗・以下} をみたすとする。このとき {Re s > a|エスの実部がエーより大きい} の範囲で、{F(s)|エフ・オブ・エス} を {f(t)e^{−st}|エフ・オブ・ティー、かける、イー・のマイナス・エス・ティー乗} の積分で定める。これがラプラス変換である。

### ch2/s04/2
使う性質は四つに限る。線形性。微分が {sF(s) − f(0)|エス・エフ・オブ・エス、マイナス、エフ・ゼロ} に移ること。畳み込みが積に移ること。そして終値定理である。変換表は使わない。

### ch2/s04/3
終値定理は次の主張である。{sF(s)|エス・エフ・オブ・エス} が閉右半平面で正則なら、{t|ティー} を無限大に飛ばした {f|エフ} の極限は、{s|エス} を 0 に近づけた {sF(s)|エス・エフ・オブ・エス} の極限に等しい。第3部で、追従の誤差が最後に残るかどうかを、この定理一行で判定する。

## s05 伝達関数

### ch2/s05/1
<!-- def 定義6 -->
定義6。初期値を 0 として状態方程式をラプラス変換すると、出力の変換は入力の変換に {G(s)|ジー・オブ・エス} を掛けたものになる。この {G(s) = C(sI − A)^{-1}B + D|ジー・オブ・エス・イコール、シー、エス・アイ・マイナス・エーの逆行列、ビー、プラス・ディー} を、入力から出力への伝達関数という。

### ch2/s05/2
1入力1出力なら、{G|ジー} は実係数の有理関数である。既約分数に書いたとき、分母の根を極、分子の根を零点と呼ぶ。

### ch2/s05/3
{|s||エスの絶対値} を無限大に飛ばしたとき {G|ジー} が有界ならプロパー、0 に収束すれば厳密にプロパーという。物理的な系の伝達関数はプロパーである。入力に対して出力が無限に速く反応することはないからだ。

## s06 伝達関数の値の意味

### ch2/s06/1
{G(s)|ジー・オブ・エス} の値そのものに意味がある。{s|エス} が {A|エー} の固有値でなければ、入力 {u(t) = e^{st}|ユー・イコール・イー・のエス・ティー乗} に対して初期値をうまく選ぶと、出力はちょうど {G(s)e^{st}|ジー・オブ・エス、かける、イー・のエス・ティー乗} になる。

### ch2/s06/2
伝達関数とは、指数関数を入れたら何倍の指数関数が出てくるかの表である。ラプラス変換を経由するより、この見方のほうが後の話につながりやすい。第4部では {s|エス} を虚軸の上に置いて、正弦波が何倍になるかを読む。

## s07 極と固有値のずれ

### ch2/s07/1
極は {A|エー} の固有値の中に含まれるが、一致するとは限らない。{(sI − A)^{-1}|エス・アイ・マイナス・エーの逆行列} の分母は {det(sI − A)|デターミナント、エス・アイ・マイナス・エー} だが、{C|シー} と {B|ビー} を掛けたあとで、その因子が分子と約分されて消えることがある。

### ch2/s07/2
消えた固有値が {ℂ₋|シー・マイナス} の外にあると、入力と出力だけを見ていても気づかない不安定が中に残る。このずれは第5部で、入力から届かない固有値、出力から見えない固有値として正確に捉え直す。

## s08 BIBO 安定

### ch2/s08/1
<!-- def 定義7 -->
定義7。有界な入力に対して、いつも有界な出力を返す系を、BIBO 安定という。バウンデッド・インプット、バウンデッド・アウトプットの頭文字である。プロパーな有理関数 {G|ジー} については、BIBO 安定であることと、極がすべて {ℂ₋|シー・マイナス} にあることが同値になる。

### ch2/s08/2
多項式の根がすべて {ℂ₋|シー・マイナス} にあるかどうかは、根を求めなくても、係数の四則演算を有限回行えば判定できる。ラウス・フルビッツの判定法である。証明は代数の演習に回し、ここでは低い次数の場合だけを使う。

### ch2/s08/3
2次式 {s² + a₁s + a₀|エス二乗・プラス・エーワン・エス・プラス・エーゼロ} なら、二つの係数がどちらも正であることが必要十分である。3次式なら、係数がすべて正で、さらに {a₂a₁ > a₀|エーツー・エーワンが、エーゼロより大きい} ことが必要十分である。

## s09 振り子の伝達関数

### ch2/s09/1
振り子に戻る。{b = 1/(Mℓ)|ビー・イコール、エム・エル・分の1} とおく。力 {u|ユー} から角度 {θ|シータ} への伝達関数は {P_θ(s) = −b/(s² − p²)|ピー・シータ・オブ・エス・イコール、マイナス・ビー、わる、エス二乗・マイナス・ピー二乗} になる。今の数値では {b|ビー} は 2 である。

### ch2/s09/2
{P_θ|ピー・シータ} の分母には、{A|エー} の固有値 0 が現れない。二つとも約分で消えている。角度だけを見ていると、台車がどこへ流れていくかは見えない。そのことが、ここでは分母の次数の低さとして表れている。

### ch2/s09/3
力から台車位置 {x|エックス} への伝達関数 {P_x|ピー・エックス} も計算しておく。こちらは右半平面に零点 {√(g/ℓ)|ルート、ジー・わる・エル} を持ち、その値はおよそ 4.43 である。この零点は、第6部で、どんな制御器でも越えられない限界として戻ってくる。
