## この講義の前提

聴き手は数学科の大学院生以上とし、線形代数（ジョルダン標準形まで）、常微分方程式の基本定理、複素関数論（留数定理と偏角原理）は既知とする。物理はニュートンの運動方程式が書ければ足りる。工学部の講義が半期をかけて行う計算練習、たとえばブロック線図の等価変換、ボード線図の手書きの作法はほぼ省き、浮いた時間を「なぜその量を見るのか」の説明に回す。

記法を先に決めておく。時刻は t ≥ 0、複素変数は s、虚数単位は工学の慣習に合わせて j と書く。ベクトルは縦ベクトルで、ᵀ は転置を表す。行列 A の固有値全体を σ(A) と書き、開左半平面 {s ∈ ℂ : Re s < 0} を ℂ₋ と書く。

扱う範囲は連続時間の線形系の解析と設計に限る。範囲外の話題は講義の中で名前を挙げない。例外は第5部の終わりの一箇所だけで、LQR の安定余裕がオブザーバを挟むと失われることを述べるために、カルマンフィルタと LQG の名前を「範囲外」と明示して出す。

全体を通す例は台車の上の倒立振り子とする。新しい道具は必ずまずこの振り子に当て、それから一般の形に書き直す。

## 標準カリキュラムと本講義の目次

日本の工学部では、制御工学は「古典制御」と「現代制御」の2科目に分かれていることが多い。古典制御は1入力1出力の系を伝達関数で扱い、モデル化、ラプラス変換、ブロック線図、過渡応答、周波数応答とボード線図、ラウス・フルビッツとナイキストの安定判別、定常偏差、補償器の設計と進む（[奈良高専のシラバス](https://www.nara-k.ac.jp/education/pdf/24_5E132.pdf)がほぼこの順）。現代制御は状態方程式から出発し、可制御性・可観測性、極配置、オブザーバ、最適レギュレータを扱う（[東北大学 制御工学IIの概要](https://qsl.cds.tohoku.ac.jp/qsl/syllabus/like/tb15021)）。

米国でも範囲は変わらない。Franklin–Powell–Emami-Naeini を教科書とする [MIT 16.06](https://ocw.mit.edu/courses/16-06-principles-of-automatic-control-fall-2012/pages/syllabus) は、根軌跡、ナイキスト判別、周波数領域設計、状態空間法を並べる。[Åström–Murray の Feedback Systems](https://www.cds.caltech.edu/~murray/amwiki/Preface_and_Table_of_Contents.html) は状態空間を先に置き、根軌跡やボード線図の手書き規則をわざと軽くしている。

## 第1部 制御の問題と倒立振り子（0–10分）

制御とは、外から加える量を時間の関数として選び、ある装置の振る舞いを望みの形にすることである。最初の10分で、この一文の語を数式に置き換える。

> [図1 台車型倒立振り子 · θ は鉛直上向きから測る — 図は Web 版で SVG として作り直す。数値は README.md §6]

**定義1（系、状態、入力、出力）** 本講義で系とは、次の常微分方程式と写像の組をいう。

```latex
\dot z(t) = f\bigl(z(t), u(t)\bigr), \qquad y(t) = h\bigl(z(t), u(t)\bigr)
```

z(t) ∈ ℝⁿ を状態、u(t) ∈ ℝᵐ を入力、y(t) ∈ ℝᵖ を出力と呼ぶ。入力はこちらが選べる量、出力はセンサで測れる量だ。制御したい系を制御対象（プラント）と呼ぶ。f は C¹ 級、u は区分連続としておけば、初期値と入力から解は局所的に一意に決まる。

**定義2（開ループと閉ループ）** 入力を時刻の既知関数として前もって決めるやり方を開ループ制御（フィードフォワード）という。出力の観測値から入力を決めるやり方、たとえば u(t) = k(y(t))、より一般には別の微分方程式を介して y から u を作るやり方をフィードバック制御といい、その結果できる自律系を閉ループ系と呼ぶ。y から u を作る規則が制御則で、それを実装したものが制御器（コントローラ）である。

振り子の設定は図1のとおり。質量 M の台車が水平な直線上を摩擦なしに動き、その上に長さ ℓ の質量のない棒と先端の質点 m からなる振り子が回転自在についている。質点の位置は (x + ℓ sin θ, ℓ cos θ) なので、運動エネルギーと位置エネルギーからラグランジュ方程式を書くと次の2本が出る。

```latex
(M+m)\ddot x + m\ell\,(\ddot\theta\cos\theta - \dot\theta^2\sin\theta) = u, \qquad \ddot x\cos\theta + \ell\ddot\theta - g\sin\theta = 0
```

**定義3（平衡点と線形化）** f(zₑ, uₑ) = 0 をみたす組 (zₑ, uₑ) を平衡点という。A = ∂f/∂z、B = ∂f/∂u、C = ∂h/∂z、D = ∂h/∂u を平衡点で評価し、平衡点からのずれ ξ = z − zₑ、v = u − uₑ について書いた系 ξ̇ = Aξ + Bv、η = Cξ + Dv を線形化系と呼ぶ。以下、記号を節約して ξ, v をあらためて z, u と書く。

振り子は z = (x, ẋ, θ, θ̇)ᵀ = 0、u = 0 が平衡点である。sin θ ≈ θ、cos θ ≈ 1 として ẍ と θ̈ について解くと、線形化系は次の形になる。

```latex
A = \begin{pmatrix} 0 & 1 & 0 & 0 \\ 0 & 0 & -\dfrac{mg}{M} & 0 \\ 0 & 0 & 0 & 1 \\ 0 & 0 & \dfrac{(M+m)g}{M\ell} & 0 \end{pmatrix}, \qquad B = \begin{pmatrix} 0 \\ \dfrac{1}{M} \\ 0 \\ -\dfrac{1}{M\ell} \end{pmatrix}
```

A の特性多項式は λ²(λ² − p²)、ただし p² = (M+m)g/(Mℓ) である。固有値 +p があるので、微小なずれは e^{pt} の速さで増える。これが「倒れる」の数学的な意味である。

以下では M = 1 kg、m = 0.1 kg、ℓ = 0.5 m、g = 9.8 m/s² を使い続ける。このとき p² = 21.56、p ≈ 4.64 s⁻¹ で、ずれは約0.22秒ごとに e 倍になる。

## 第2部 線形系の解、安定性、伝達関数（10–25分）

線形系 ż = Az + Bu、y = Cz + Du の解は定数変化法で書ける。数学科の聴き手には式を見せるだけでよい。

```latex
z(t) = e^{At} z(0) + \int_0^t e^{A(t-\tau)} B\, u(\tau)\, d\tau
```

**定義4（安定性）** 自律系 ż = f(z)、f(0) = 0 を考える。任意の ε > 0 に対し δ > 0 があって |z(0)| < δ ならばすべての t ≥ 0 で |z(t)| < ε となるとき、原点はリアプノフ安定であるという。さらに原点の近くから出た解が t → ∞ で 0 に収束するとき漸近安定という。工学で単に「安定」と言えばたいてい漸近安定のことである。σ(A) ⊂ ℂ₋ をみたす行列 A をフルビッツ行列（安定行列）と呼ぶ。

**命題1** ż = Az の原点が漸近安定であることと A がフルビッツであることは同値。非線形系については、線形化 A がフルビッツなら平衡点は漸近安定、A が実部正の固有値をもてば不安定である（リアプノフの間接法）。

前半はジョルダン標準形から直ちに出る。後半により、図2の +p は線形化の中だけの話ではなく、非線形の振り子そのものが倒れることの証明になっている。

> [図2 線形化した振り子の A の固有値 · M=1, m=0.1, ℓ=0.5 — 図は Web 版で SVG として作り直す。数値は README.md §6]

**定義5（ラプラス変換）** \[0, ∞) 上の局所可積分関数 f がある K, a について |f(t)| ≤ Ke^{at} をみたすとき、Re s > a で F(s) = ∫₀^∞ f(t)e^{−st} dt と定める。使う性質は線形性、微分則 ℒ\[f′\] = sF(s) − f(0)、畳み込みが積になること、そして終値定理の四つだけである。終値定理とは、sF(s) が閉右半平面 Re s ≥ 0 で正則なら lim\_{t→∞} f(t) = lim\_{s→0} sF(s) が成り立つという主張である。

**定義6（伝達関数、極、零点、プロパー）** z(0) = 0 のとき、状態方程式をラプラス変換すると Y(s) = G(s)U(s) の形になる。

```latex
G(s) = C(sI - A)^{-1}B + D
```

この G を入力 u から出力 y への伝達関数という。1入力1出力なら G は実係数の有理関数で、既約分数に書いたときの分母の根を極、分子の根を零点と呼ぶ。|s| → ∞ で有界ならプロパー、0に収束すれば厳密にプロパーという。物理的な系の伝達関数はプロパーである。

G(s) の値には直接の意味がある。s が A の固有値でなければ、入力 u(t) = e^{st} に対して適当な初期値を選ぶと出力はちょうど y(t) = G(s)e^{st} になる。伝達関数とは「指数関数を入れたら何倍の指数関数が出てくるか」の表であり、この説明のほうがラプラス変換より数学科には通りがよい。

極は σ(A) に含まれるが、一致するとは限らない。(sI − A)⁻¹ の分母 det(sI − A) の因子が C や B を掛けたときに約分で消えることがあるからだ。消えた固有値が ℂ₋ の外にあれば、入出力だけ見ていると気づかない不安定が中に残る。

**定義7（BIBO安定）** 有界な入力に対して常に有界な出力を返すとき、系は BIBO 安定（bounded-input bounded-output）であるという。プロパーな有理関数 G については、BIBO 安定であることとすべての極が ℂ₋ にあることは同値である。

多項式の根がすべて ℂ₋ にあるかどうかは、根を求めなくても係数の有限回の四則演算で判定できる（ラウス・フルビッツの判定法）。本講義で使うのは低次の場合だけである。s² + a₁s + a₀ なら a₁ > 0 かつ a₀ > 0、s³ + a₂s² + a₁s + a₀ なら係数がすべて正で a₂a₁ > a₀ が必要十分である。

振り子に戻る。b = 1/(Mℓ) とおき、力 u から角度 θ への伝達関数と、力 u から台車位置 x への伝達関数を計算すると次のようになる。

```latex
P_\theta(s) = \frac{-b}{s^2 - p^2}, \qquad P_x(s) = \frac{s^2 - g/\ell}{M\, s^2 (s^2 - p^2)}
```

P_θ には A の固有値 0（2重）が現れない。角度だけを見ていると台車がどこへ流れていくかは見えない、ということの代数的な表れである。もう一つ、P_x には右半平面の零点 +√(g/ℓ) ≈ 4.43 がある。この零点は第6部で根本的な限界として戻ってくる。

## 第3部 フィードバックの構造（25–42分）

> [図3 標準的なフィードバック系 · 1入力1出力 — 図は Web 版で SVG として作り直す。数値は README.md §6]

**定義8（標準フィードバック系）** 図3の系で、r を参照信号（目標値）、e = r − y を偏差、d を外乱と呼ぶ。外乱とはこちらが選べず値も知らない入力のことで、振り子なら台車を軽く小突く力がそれに当たる。L(s) = P(s)C(s) をループ伝達関数、

```latex
S = \frac{1}{1+L}, \qquad T = \frac{L}{1+L} = 1 - S
```

をそれぞれ感度関数、相補感度関数と呼ぶ。図をそのまま方程式にすれば Y = TR + PSD、E = SR − PSD が得られる。工学部で時間をかける「ブロック線図の等価変換」は、この種の連立一次方程式を絵で解く技術である。

S の名前の由来は次の計算にある。制御対象が P から少しずれたときの T の相対変化は (dT/T)/(dP/P) = S である。つまり |S(jω)| が小さい周波数では、モデルの誤差も外乱も出力にはほとんど現れない。フィードバックを掛ける理由は、この1行に尽きる。

**定義9（内部安定）** (r, d) から (e, u) への4つの伝達関数がすべて BIBO 安定のとき、閉ループ系は内部安定であるという。P = n_P/d_P、C = n_C/d_C をそれぞれ既約に書くと、内部安定であることは特性多項式 d_P d_C + n_P n_C の根（閉ループ極）がすべて ℂ₋ にあることと同値である。r から y への T だけでは足りない。不安定な極を C の零点で打ち消すと T は安定に見えても、d から y への経路が発散する。第2部の「約分で消える固有値」と同じ話である。

次に、応答の「良さ」を測る語を定める。

**定義10（ステップ応答とその指標）** 初期値 0 から単位ステップ入力（t ≥ 0 で 1 の定数関数）を加えたときの出力をステップ応答という。安定な系ではステップ応答は定常値 y_∞ = G(0) に収束する。最大値が y_∞ を超える割合を行き過ぎ量（オーバーシュート）、応答が y_∞ の ±2% の帯に入って以後出なくなる時刻を整定時間という（帯を ±5% にとる流儀もある）。参照信号がステップのときの lim e(t) を定常偏差という。

> [図4 2次系のステップ応答 · 解析解 — 図は Web 版で SVG として作り直す。数値は README.md §6]

図4は 2次系 G(s) = ωₙ²/(s² + 2ζωₙs + ωₙ²) の応答である。ζ を減衰係数、ωₙ を固有角周波数と呼ぶ。極は −ζωₙ ± jωₙ√(1−ζ²) で、行き過ぎ量は exp(−πζ/√(1−ζ²)) とζだけで決まり、整定時間は概ね 4/(ζωₙ) である。「極が虚軸から遠いほど速く落ち着き、実軸からの角度が大きいほど振動的になる」という直観は、高次の系でも支配的な極についておおむね通用する。

定常偏差は終値定理から一行で出る。閉ループが内部安定なら、ステップ参照に対する定常偏差は S(0) = 1/(1 + L(0)) である。L が s = 0 に極（積分器）をもてば S(0) = 0 で、偏差は残らない。一般に、消したい信号を生成するモデル（ステップなら 1/s、周波数 ω₀ の正弦波なら 1/(s²+ω₀²)）をループの中に含めればよい。これを内部モデル原理と呼ぶ。

**定義11（PID 制御）** 偏差の現在値、積分、微分の線形結合で入力を作る制御則

```latex
u(t) = k_p\, e(t) + k_i \int_0^t e(\tau)\, d\tau + k_d\, \dot e(t), \qquad C(s) = k_p + \frac{k_i}{s} + k_d s
```

を PID 制御という。k_i = 0 のものを PD 制御と呼ぶ。一般に、信号に掛ける倍率をゲインと呼び、k_p, k_i, k_d をそれぞれ比例ゲイン、積分ゲイン、微分ゲインという。積分項は上の内部モデル原理の最も簡単な実例であり、微分項は減衰を与える。実際の実装では k_d s をそのまま使わず、高周波を切るフィルタを掛ける。

振り子を PD 制御で立てる。目標は θ = 0 なので r = 0 とし、P_θ = −b/(s² − p²) の符号を打ち消すために C(s) = −(k_p + k_d s) と置く。特性多項式は次のとおり。

```latex
s^2 + b k_d\, s + (b k_p - p^2)
```

2次のラウス・フルビッツ条件から、内部安定であるための必要十分条件は k_d > 0 かつ k_p > p²/b = (M+m)g である。後者は「角度に比例して押す強さが、重力が振り子を倒そうとする強さに勝っている」と読める。数値では b = 2、(M+m)g = 10.78 であり、k_p = 43、k_d = 4 とすれば特性多項式は s² + 8s + 64.44、つまり ωₙ ≈ 8.0、ζ ≈ 0.50 になる。図4はちょうどこの極の配置をもつ 2次系の応答である。

k_d = 4 を固定して k_p を 0 から増やすと、閉ループ極 s = −4 ± √(37.56 − 2k_p) は次のように動く。k_p < 10.78 では正の実根があり倒れ、k_p = 10.78 で根が原点を横切り、18.78 までは負の実根が2つ、それを超えると実部 −4 の共役複素根になる。このようにゲイン k_p を動かしたときの根の軌跡を複素平面に描いたものを根軌跡という。工学部では作図規則を教えるが、ここでは「係数が連続に動けば根も連続に動く」という事実の絵だと説明すれば足りる。

ここで一つ問題が残る。θ は立ったが、台車はどうなったか。θ だけを見る制御器は A の固有値 0（2重）に触れていないので、台車は一般に一定速度でどこかへ走り去る。台車も振り子も同時に止めるには4つの状態をまとめて扱う必要があり、それが第5部の仕事になる。

## 第4部 周波数応答とナイキストの安定判別（42–65分）

**定義12（周波数応答、ボード線図）** G を BIBO 安定な伝達関数とする。入力 u(t) = sin ωt に対する出力は、過渡項が消えたあと |G(jω)| sin(ωt + arg G(jω)) になる。ω ≥ 0 の関数 G(jω) を周波数応答、arg G(jω) を位相と呼ぶ。|G(jω)| は正弦波の振幅が何倍になるかを表すので、定義11の意味で周波数 ω でのゲインと呼ぶ。横軸に log ω、縦軸に 20 log₁₀|G|（単位デシベル、dB）と位相をとった2枚組のグラフをボード線図という。対数をとるのは、直列につないだ要素の積がグラフの和になるからである。

不安定な G では正弦波への応答という解釈は成り立たないが、G(jω) という複素数の値そのものは定義できる。ナイキストの定理が使うのはこの値のほうである。

> [図5 ボード線図 · L(jω) を ω = 0.1–316 rad/s で計算 — 図は Web 版で SVG として作り直す。数値は README.md §6]

**定義13（ナイキスト線図）** 虚軸を下から上へ、つまり ω を −∞ から +∞ まで動かしたときの L(jω) の像を、向きつきの閉曲線として複素平面に描いたものをナイキスト線図という。L が虚軸上に極をもつときは、その極を右側の小さな半円で避ける。

**定理（ナイキストの安定判別法）** L = PC をプロパーな有理関数とし、P と C の間で不安定な極と零点の約分は起きていないとする。L の開右半平面にある極の個数（重複度込み）を P、ナイキスト線図が −1 を反時計回りに回る回数を N とする。このとき、閉ループ系が内部安定であることと N = P は同値である。

証明。閉ループ極は 1 + L の零点であり、そのうち開右半平面にあるものの個数を Z とする。1 + L の極は L の極と同じだ。虚軸と半径 R の右半円からなる閉曲線を時計回りにたどると、偏角原理により 1 + L の像は原点を時計回りに Z − P 回る。L はプロパーなので R → ∞ で半円の像は1点に潰れる。「1 + L が原点を回る」は「L が −1 を回る」と同じことなので、N = P − Z が得られる。Z = 0 と N = P は同値である。□

振り子に当てる。第3部の PD 制御では L(s) = 2(43 + 4s)/(s² − 21.56) で、不安定極は s = +p の1個だから P = 1 である。図6を見ると、曲線は原点から上半平面を通って L(0) ≈ −3.99 に至り、下半平面を通って原点に戻る。−1 はその内側にあり、反時計回りに1周されているので N = 1 = P、閉ループは安定である。k_d = 0 の PD 制御（k_p の項だけ）なら L(jω) は実軸上の線分に潰れ、何も回れない。k_p の項だけでは振り子を立てられないことが、第3部の代数とは別の形で分かる。

> [図6 ナイキスト線図 · ω < 0 の半分は ω > 0 の共役 — 図は Web 版で SVG として作り直す。数値は README.md §6]

**定義14（安定余裕）** |L(jω_c)| = 1 となる周波数 ω_c をゲイン交差周波数といい、180° + arg L(jω_c) を位相余裕という。ナイキスト線図が負の実軸と交わる点が −a（a > 0）のとき、ループのゲインを何倍まで変えると曲線が −1 を通るかをゲイン余裕という。どちらも、モデルと実物のずれがどこまで許されるかの目安である。

振り子では ω_c ≈ 9.7 rad/s、位相余裕は約42°である（図5）。ゲイン余裕のほうは少し変わっている。曲線が負の実軸と交わるのは ω = 0 の −3.99 だけなので、ゲインを上げても不安定にはならない。代わりに 1/3.99 ≈ 0.25 倍（約 −12 dB）より下げると周回が外れて倒れる。「制御を弱めると安定側に寄る」という直観は、制御対象そのものが不安定なときには成り立たない。これは k_p > 10.78 という第3部の条件の言い換えになっている（43 × 0.25 ≈ 10.78）。

ここから設計の考え方が出てくる。低い周波数では |L| を大きくして |S| を小さくしたい（追従と外乱抑制）。高い周波数ではセンサ雑音やモデル化していない高次の振動が効いてくるので |L| を小さくしたい。その間を十分な位相余裕を保ったまま渡るように C を選ぶことをループ整形という。交差周波数付近で位相を進める要素 (1 + s/a)/(1 + s/b)（a < b）を位相進み補償、低域のゲインだけを上げる要素を位相遅れ補償と呼ぶ。

この「渡る」ことには制約がある。右半平面に極も零点ももたない安定な L では、位相はゲイン曲線から一意に決まり、ω が10倍になるごとにゲインが 20 dB の割合で下がる区間では位相はおよそ −90° になる（ボードのゲイン・位相関係、実部と虚部のヒルベルト変換対と同じ構造）。ゲインを急に落とすと位相が −180° に近づき余裕がなくなるので、交差周波数の前後では緩やかにしか下げられない。

## 第5部 状態空間での設計（65–92分）

**定義15（状態フィードバック）** 行列 K ∈ ℝ^{m×n} を用いて u = −Kz とする制御則を状態フィードバックという。閉ループ系は ż = (A − BK)z である。状態がすべて測れるという仮定は、あとで出力から状態を推定することで外す。

**定義16（可制御性）** 任意の z₀, z₁ ∈ ℝⁿ と T > 0 に対し、\[0, T\] 上の入力 u で z(0) = z₀ から z(T) = z₁ へ移せるとき、(A, B) は可制御（可到達）であるという。行列 𝒞 = \[B, AB, …, A^{n−1}B\] を可制御性行列と呼ぶ。

**定理（カルマンの階数条件）** (A, B) が可制御であることと rank 𝒞 = n は同値である。

証明の骨格。時刻 T に 0 から届く点全体は、線形写像 u ↦ ∫₀ᵀ e^{A(T−τ)}Bu(τ)dτ の像である。その直交補空間に属する v は、すべての t で vᵀe^{At}B = 0 を満たす。t = 0 で微分を繰り返せば vᵀAᵏB = 0（k = 0, 1, …）となり、逆もテイラー展開から従う。ケイリー・ハミルトンの定理により k ≤ n − 1 で十分である。□

同じことを固有値ごとに言い換えたのが PBH 判定法である。すべての λ ∈ ℂ で rank \[λI − A, B\] = n なら可制御で、この階数が落ちる λ が「入力から届かない固有値」になる。届かない固有値がすべて ℂ₋ にあるとき、(A, B) は可安定であるという。

**定理（極配置）** 1入力系について、(A, B) が可制御であることと、任意の n 次実モニック多項式 χ に対し det(sI − A + BK) = χ(s) となる K が存在することは同値である。

証明は座標変換で (A, B) を可制御正準形（A が同伴行列、B = e_n）に移すだけである。この形では BK は最後の行だけを書き換え、最後の行は特性多項式の係数そのものなので、係数を好きに選べる。逆向きは、届かない固有値が K をどう選んでも動かないことから従う。

振り子で確かめる。第1部の A, B から 𝒞 を作ると |det 𝒞| = g²/(M⁴ℓ⁴) ≠ 0 で、可制御である。数値では 1536.64 である。したがって 4つの固有値をたとえば −2, −3, −4, −5 に置く K が一意に存在し、計算すると K ≈ (−6.12, −7.86, −49.34, −10.93) となる。第3部の PD 制御に欠けていた台車の位置と速度も、ここで初めてフィードバックされる。

**定義17（可観測性）** 入力と出力を \[0, T\] で観測すれば初期状態 z(0) が一意に定まるとき、(C, A) は可観測であるという。先の定理を (Aᵀ, Cᵀ) に当てれば、可観測性は可観測性行列 \[C; CA; …; CA^{n−1}\] の階数が n であることと同値になる。可制御性と可観測性は転置で入れ替わる双対な概念であり、証明を繰り返す必要はない。観測できない固有値がすべて ℂ₋ にあるとき、(C, A) は可検出であるという。

振り子では、台車位置 x だけを測る C = (1, 0, 0, 0) なら可観測である。角度 θ だけを測る C = (0, 0, 1, 0) では可観測性行列の階数が 2 しかない。角度をいくら見ても台車がどこにいるかは分からない。第2部で P_θ から固有値 0 が消えていたのは、まさにこのことだった。

**定義18（オブザーバ）** 推定値 ẑ を次の微分方程式で作る系を（同一次元）オブザーバという。H は設計者が選ぶ行列で、オブザーバゲインと呼ぶ。

```latex
\dot{\hat z} = A\hat z + Bu + H\,(y - C\hat z)
```

誤差 ε = z − ẑ は ε̇ = (A − HC)ε に従う。A − HC の固有値は、双対性により (C, A) が可観測なら自由に置ける。

**定理（分離定理）** 状態の代わりに推定値を使って u = −Kẑ とすると、閉ループの固有値は σ(A − BK) ∪ σ(A − HC) になる。(z, ε) を座標にとれば係数行列がブロック上三角になるので、証明は1行である。制御器と推定器を別々に設計してよい、というのが工学上の意味である。

ここまでで「固有値をどこにでも置ける」ことは分かったが、どこに置けばよいかは決まっていない。左に遠く置くほど速く収束するが、入力が大きくなり、雑音にも敏感になる。この兼ね合いを目的関数で書いたのが次の問題である。

**定理（最適レギュレータ、LQR）** Q ⪰ 0、R ≻ 0 とし、評価関数

```latex
J = \int_0^\infty \bigl( z^\top Q z + u^\top R u \bigr)\, dt
```

を考える。(A, B) が可安定で (Q^{1/2}, A) が可検出なら、代数リッカチ方程式

```latex
A^\top X + XA - XBR^{-1}B^\top X + Q = 0
```

は A − BR⁻¹BᵀX をフルビッツにする半正定値の解 X をただ一つもち、J を最小にする入力は状態フィードバック u = −R⁻¹BᵀXz、最小値は z(0)ᵀXz(0) である。

最適性の方は平方完成で示せる。任意の安定化入力に対して d/dt(zᵀXz) を計算し、リッカチ方程式を使うと、被積分関数は −d/dt(zᵀXz) + (u + R⁻¹BᵀXz)ᵀR(u + R⁻¹BᵀXz) になる。積分すれば J = z(0)ᵀXz(0) + (非負の項) である。解の存在と一意性はハミルトン行列の安定不変部分空間を使う話になるので、講義では主張だけにする。

振り子で Q = diag(10, 1, 100, 1)、R = 1 とすると K ≈ (−3.16, −4.43, −39.58, −8.48)、閉ループ固有値は −5.17 ± 1.72j と −1.10 ± 0.94j になる。Q の第3成分を大きくしたのは、台車のずれより角度のずれを重く罰したいからである。この K を線形化していない元の運動方程式に適用したのが図7である。

> [図7 LQR を非線形の振り子に掛けた数値解 · SciPy solve\_ivp、0.1 s 刻みで表示 — 図は Web 版で SVG として作り直す。数値は README.md §6]

右に 0.2 rad 傾いた振り子を立て直すために、台車はまず右へ約 0.35 m 走って振り子の下に回り込み、それから原点へ戻る。入力の最大値は約 7.9 N だった。第3部の PD 制御と違い、台車も置き去りにならない。

1入力の LQR にはロバスト性のおまけがつく。入力の位置でループを切った L(s) = K(sI − A)⁻¹B について |1 + L(jω)| ≥ 1 がすべての ω で成り立ち（カルマンの不等式）、位相余裕は 60° 以上、ゲインは 1/2 倍から無限大倍まで変えても安定を保つ。ただしオブザーバを挟むとこの保証は消える。特に、ガウス雑音のもとで最適な H を双対なリッカチ方程式で求めたもの（カルマンフィルタ）と組んだ LQG 制御器でも、安定余裕はいくらでも小さくなりうる。カルマンフィルタと LQG はどちらも本講義の範囲外で、ここでは名前だけを挙げる。この事実が次の部への橋渡しになる。

## 第6部 ロバスト性と根本的な限界（92–102分）

**定義19（H∞ ノルム、ロバスト安定）** ℂ₋ に極をもつプロパーな G に対し ‖G‖∞ = sup_ω |G(jω)| と定める。制御対象の真の伝達関数が集合 {P(1 + WΔ) : Δ は安定、‖Δ‖∞ ≤ 1} のどれかだと分かっているとする。W は「各周波数でモデルが何割ずれているか」を表す重みである。この集合のすべての元に対して閉ループが内部安定なとき、制御器はロバスト安定化するという。ナイキストの定理から、その必要十分条件は ‖WT‖∞ < 1 である。ナイキスト曲線上の各点を動かしても −1 を跨がない、という条件を書き下しただけである。

**定理（ボードの感度積分）** L の相対次数（分母と分子の次数の差）が 2 以上で、閉ループが内部安定とする。L の開右半平面の極を p₁, …, p_k とすると、次が成り立つ。

```latex
\int_0^\infty \log |S(j\omega)|\, d\omega = \pi \sum_{i=1}^{k} \operatorname{Re} p_i
```

右辺は非負なので、ある周波数帯で |S| < 1 にして外乱を抑えれば、必ずどこかで |S| > 1 となり外乱が増幅される。地面を一箇所で踏み込むと別の場所が盛り上がる、という比喩で知られている。証明は log S を右半平面の大きな半円で囲んでコーシーの積分定理を使う。不安定極は S の零点になるので、その寄与をブラシュケ積で外してから計算すれば右辺が出る。

振り子では右辺は πp ≈ 14.6 である。第3部の PD 制御の L は相対次数1なのでこの形では当てはまらないが、実際には微分項にフィルタを掛けるので相対次数は 2 以上になる。p² = (M+m)g/(Mℓ) なので、棒が短いほど右辺は大きく、支払うべき「盛り上がり」も大きい。短い棒のほうが手の上で立てにくいという経験と一致する。

**定義20（非最小位相）** 開右半平面に零点をもつ伝達関数を非最小位相であるという。そういう零点 z があると、内部安定性から S(z) = 1 を避けられない。最大値原理により ‖S‖∞ ≥ 1 であり、さらに右半平面の極 p もあれば次の下界が得られる。

```latex
\|S\|_\infty \ge \left| \frac{z + p}{z - p} \right|
```

第2部で求めた P_x は、右半平面に零点 z = √(g/ℓ) ≈ 4.43 と極 p ≈ 4.64 をもつ。台車の位置 x だけを測って振り子を立てようとすると、どんな制御器を使っても ‖S‖∞ ≥ 9.07/0.216 ≈ 42 となる。ある周波数の外乱が40倍以上に増幅されるのだから、実用上は立たないと考えてよい。第5部では y = x で可観測だと確かめたが、可観測であることと実際に扱えることは別の問題である。角度センサを足して系を多出力にすれば、この壁は大きく下がる。

## まとめ（102–105分）

最後の3分では、第1部の一文「外から加える量を選び、振る舞いを望みの形にする」に戻り、各部がそのどの語を精密にしたかを振り返る。第1部が「外から加える量」と「装置」を入力と系に、第2部が「振る舞い」を固有値と極に、第3・第4部が「望みの形」を感度と安定余裕に、第5部が「選び」を可制御性と最適化にした。第6部は、その形には対象ごとに越えられない上限があることを示した。

次に読むものとしては、全体の見通しに Åström–Murray『Feedback Systems』、数学的に厳密な扱いに Sontag『Mathematical Control Theory』、第6部の続きに Doyle–Francis–Tannenbaum『Feedback Control Theory』を挙げる。

カルマンフィルタと LQG は名前だけ出している。ビデオでも定義せず「範囲外」と明示する。

ビデオで動かすと効果が大きいのは次の4場面である。図7の数値解を使った振り子のアニメーション（PD では台車が流れ、LQR では戻る対比）。k_p をスライダで動かして閉ループ極が動く根軌跡。ω を動かして点 L(jω) がナイキスト曲線をたどり、同時にボード線図上の縦線が動く連動表示。ループのゲイン（k_p と k_d を同じ倍率で）を 0.25 倍より下げたときに周回が外れる瞬間。

ナレーション原稿について。AI らしさは個々の言い回しよりも、同じ型の繰り返しで生じる。「A ではなく B」で問いを立て、「つまり」で言い換え、「と言えるでしょう」で締める流れが段落ごとに繰り返されると、単調な印象になるという指摘がある（[issoh](https://www.issoh.co.jp/md/column/2736)）。英語圏の計測では、過剰なマークダウンや箇条書き、三つ組の列挙、「X だけでなく Y も」が人間の文章より目立って多いとされる（[Pangram](https://www.pangram.com/ja/signs-of-ai-writing)）。一方で、日本語で「AIらしい」と言われる特徴を実測と照合した小規模な調査では、裏付けられたのは読点の多さだけだったという（[fyve の紹介記事](https://fyve.co.jp/ai-advisor/articles/ai-text-detection-myths-japan)）。このスケッチでは、締めの決まり文句を使わず、段落の最初に結論を置き、形容詞の代わりに振り子の数値（4.64、42°、0.35 m）を書くことで対処した。台本化の際も同じ方針をとり、最後は実際に声に出して読んで引っかかる箇所を削るのが確実である。
