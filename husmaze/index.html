これまでの記録

    あそびかた

    • スマホ本体を傾けるとボールが転がります。スタートしたときの持ち方が「水平」です（⊙ ボタンで取り直し）
    • PC画面の中心から見てマウスのある方向へ転がります。中心から離すほど強く傾きます。矢印キー / WASD でも操作できます
    • 迷路日本時間の日付ごとに全員同じ迷路です。毎日 0 時に変わります
    • ゴーストその日のベストの走りが半透明の玉乗りで一緒に走ります

    アイテム

    金の枠は取ると得、紫の枠は取ると損。
    良いアイテムは行き止まりに置かれがち。寄り道するかは腕しだい！

    虹の枠は大当たり。迷路の外周の、大きく遠回りになる場所に光の柱が立っています（画面の外なら端に矢印）。 −30 秒の「母は偉大なり」への道には罠が仕掛けてあるので、バリアがあると安心です。
