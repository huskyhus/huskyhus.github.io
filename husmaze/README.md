# ハスメイズ

スマホを傾けて、玉乗りをするハスキーを日替わりの迷路のゴールまで転がすタイムアタックゲームです。
HTML / CSS / JavaScript だけで動く静的サイトで、3D の描画には [Three.js](https://threejs.org/) r169（MIT ライセンス、`vendor/` に同梱）を使っています。
3D なのは見た目だけで、ボールの動きと当たり判定は 2D（真上から見た平面）で計算しています。

## 遊び方

| 操作 | スマホ | PC |
| --- | --- | --- |
| 転がす | 本体を傾ける（センサーが使えないときはドラッグ） | 画面中央から見たマウスの方向 / 矢印キー / WASD |
| 水平の取り直し | ⊙ ボタン | — |
| 一時停止 | ⏸ ボタン | ⏸ / Esc / P |

- 迷路は **日本時間の日付をシード** にして自動生成されます（12×18 マス）。同じ日なら誰でも同じ迷路です
- クリアタイムは「時計 ± アイテムの増減」。大当たりを取ればマイナスにもなります（タイマーが緑になります）。日付ごとのベストとプレイ回数を `localStorage` に保存します
- ベストを出したときの軌跡を保存し、次から **ゴースト** として半透明の玉乗りが一緒に走ります
- クリア画面から結果をシェア（共有シート / クリップボード）または X にポスト

## プレイヤー

「忘れるなよ」のハスキーが、縞模様のボールに乗って（玉乗りで）進みます。
ボールは転がって回りますが、乗っているハスキーはステッカーから全身を切り抜いた立ち絵（`avatars/wasureru.png`）で、
いつもカメラのほうを向いたまま回りません。
傾けた向きと速さに合わせて足もとを軸に体を傾け、ばねのように揺れ戻してバランスを取ります。
大きく傾いているとき（約 26° 以上）は、頭のまわりのランダムな位置から汗のしずくが飛び散ります
（調整は [js/render.js](js/render.js) の `RIDER_LEAN` / `LEAN_*` / `SWEAT_*`）。

動きはゆっくりだが慣性が弱く、思いどおりに動かせる性能です。数値は [js/player.js](js/player.js) で調整できます。

立ち絵は、ステッカー `744223938.png` の (105, 70)–(250, 215) を切り出して、背景除去ツール [rembg](https://github.com/danielgatis/rembg)（モデル `u2net`）で背景を消し、
半透明のもやと離れた小さな塊を取り除いたものです。

## アイテム

ステッカーのセリフに合わせて効果を決めています。金の枠は良いアイテム、紫の枠は悪いアイテム、虹の枠は大当たりです。

### 置き方（マップ全体を使わせる工夫）

迷路の生成（[js/maze.js](js/maze.js)）で、最短ルートから各マスまでの寄り道の長さを測り、それをもとに置きます。

1. **ぶっ壊れ（−30 秒）を 1 個**: 外周 2 マス以内で、最短ルートから片道およそ 18 マスの寄り道になるマス（行き止まりを優先）。
   いちばん遠いマスにすると日によって往復 100 マスを超えて割に合わなくなるので、遠さをそろえています（60 日分で往復 22〜44 マス）
2. **罠**: ぶっ壊れから最短ルートへ戻る枝道の途中に、悪いアイテムを 2 個並べます。バリアがあれば無傷で通れます
3. **お宝（−10 秒）を 2 個**: 外周付近で、片道およそ 7 マスの寄り道になり、ぶっ壊れやお互いから 7 マス以上離れたマス
4. **残りのアイテム**: すでに置いたアイテムからいちばん遠いマスを順に選び、マップ全体に散らします
   （良いアイテム 8 個は行き止まり・ルートの外、悪いアイテム 7 個は半分を最短ルート上）。60 日分で、迷路を 3×3 に分けた 9 区画すべてにアイテムがあります

大当たりには遠くから見える光の柱が立ち、画面の外にあるときは画面の端に方向と秒数の矢印が出ます。

| ステッカー | 種類 | 効果 |
| --- | --- | --- |
| 母は偉大なり | 大当たり | タイム −30 秒（1 個） |
| 父は森 | 大当たり | タイム −10 秒（2 個） |
| ありがたさ痛感 | 良 | タイム −3 秒 |
| 時は満ちた | 良 | 12 秒間 スローモーション。時計は 0.35 倍、ボールの動きは 0.6 倍、傾きの効きは 0.7 倍、BGM は 0.7 倍のテンポ（時計のほうが遅いので差し引きで得） |
| 準備完了！ | 良 | 4 秒間ダッシュ（加速・最高速 1.6 倍） |
| 今日はチートデイ | 良 | 3 秒間 空中に浮いて壁を飛び越える（当たり判定は壁をすり抜け、見た目は壁より高く浮く） |
| めざせ規則生活 | 良 | 8 秒間 通路の真ん中を走るようにアシスト（進む向きと垂直な方向にだけ、マスの中心線へ引き寄せる） |
| 逆転劇 | 良 | ゴールへの道を 10 マス先へワープ |
| 欲望よさらば | 良 | 悪い効果を消し、8 秒間 悪いアイテムを無効化 |
| 不可能です！ | 悪 | 5 秒間 操作が逆になる |
| やっちまった！ | 悪 | 6 秒間 つるつる滑って止まれない |
| 寝る子は育つ | 悪 | タイム ＋3 秒 |
| 地の獄 | 悪 | タイム ＋10 秒。置いてある間、大当たりの光の柱と同じ形の、赤黒いオーラの柱をまとう |
| おのれの愚かさ今知る | 悪 | 6 秒間 まわりが真っ暗に |

効果の数値は [js/items.js](js/items.js) と [js/game.js](js/game.js) の先頭の定数で調整できます。

## BGM

`musiclab/` と同じ仕組み（音声ファイルを使わず Web Audio で合成）で、スーパーハスタワーを鳴らしています。
`music/` に musiclab の `lib/`（エンジン・楽器・卓・声部の組み立て・音楽理論・スーパーハスタワーの編成）と、曲のスケッチをそのままコピーしています。
曲を直したときは musiclab で直してから、同じファイルをコピーし直してください。

- タイトルでもプレイ中でも途切れずに鳴り続けます（最初にどこかを押したときから鳴り始めます。ブラウザの自動再生制限のため）
- スローモーション中はテンポが 0.7 倍になります
- 🎵 ボタン（タイトルと HUD）でオン / オフ。設定は保存されます

## ローカルで動かす

ES モジュールを使うため、`file://` で開いても動きません。**このフォルダ（`husmaze/`）** でローカルサーバーを立ててください。

```sh
uv run python -m http.server 8002
```

- ゲーム: http://localhost:8002/
- デバッグ: http://localhost:8002/?debug （コンソールから `husmaze.game` / `husmaze.maze` / `husmaze.scene` を触れます。
  例: `husmaze.game.effects.slow = 6` でスローモーション）
- 別の日の迷路: http://localhost:8002/?date=2026-12-24

### スマホの傾きセンサーについて

傾きセンサー（DeviceOrientation）は **HTTPS でないと使えません**（iOS / Android とも）。
同じ Wi-Fi のスマホから `http://<PC の IP>:8002` で開くとセンサーが使えず、自動的にドラッグ操作になります。
センサーを試すときは GitHub Pages に置くか、`cloudflared tunnel --url http://localhost:8002` などで HTTPS の URL を作ってください。
iOS では「スタート」を押したときに、モーションへのアクセス許可を求めるダイアログが出ます。

## 構成

```
husmaze/
├── index.html
├── css/style.css
├── stickers/          ステッカー画像（hustower からコピー）
├── avatars/           玉乗りするハスキーの立ち絵（ステッカーから全身を切り抜いた透過 PNG）
├── vendor/            Three.js（three.module.min.js と LICENSE）
├── music/             musiclab からコピーした BGM のエンジンと曲
│   ├── lib/           engine / synth / mix / layers / theory / superband
│   └── sketches/      hustower-super
└── js/
    ├── game.js        メインループ・物理・アイテムの効果・記録・UI
    ├── maze.js        迷路の生成（穴掘り法 + ループ）・アイテムの配置・壁の当たり判定用の長方形
    ├── items.js       アイテムの定義（ステッカーと効果の対応）
    ├── player.js      プレイヤーの定義（立ち絵・動き）
    ├── input.js       傾き入力（センサー / マウス / ドラッグ / キーボード）
    ├── render.js      3D 描画（Three.js）。盤面・壁・アイテム・玉乗り（ボール + 立ち絵）・粒・カメラ
    ├── bgm.js         BGM（music/ のエンジンでスーパーハスタワーを鳴らす）
    ├── audio.js       効果音（Web Audio で合成）
    └── rng.js         日付シードの乱数
```
