# ハスPUBG

人と CPU あわせて最大 24 人で遊ぶ、PC 向けの 3D バトルロワイヤル（FPS）です（人どうしは 3〜4 人を想定）。飛行機からパラシュートで降り、建物の中の武器や回復を拾い、縮んでいく安全地帯の中で最後の 1 人をめざします。
HTML / CSS / JavaScript だけで動く静的サイトで、サーバーやデータベースは使いません。

- 描画: [three.js](https://threejs.org/) r169（MIT、`vendor/` に同梱）
- 通信: [PeerJS](https://peerjs.com/) 1.5.4（MIT、`vendor/` に同梱）の公開サーバーで相手を見つけ、以降はすべて WebRTC の P2P 接続の中でやりとり
- 素材: `public/` の「ハス君シリーズ④」24 枚だけ（`stickers/` にコピー）。音は WebAudio で合成

## 遊び方

1. 名前と「頭のパネル」（アバター。24 枚のステッカーから選ぶ）を決める
2. **ルームを作る** → 5 桁の部屋番号が出るので友だちに伝える。友だちは番号を入れて **ルームに入る**
   - ホストは「＋ CPU」「＋5」「満員まで」で CPU を足せます（人 + CPU で 24 人まで）。2 人以上でスタート
   - CPU はホストの中で動くので、増やしても通信の往復は増えません（ホストが配る「全員の位置」が 1 人あたり 60 文字ほど増えるだけ）
   - 頭のパネル（アバター）は全員別（ステッカー 24 枚 = 最大人数）。ほかの人が使っているものは選べず、CPU が使っているものを選ぶと CPU と入れかわります
   - **ひとりで練習** は通信なしで CPU 9 人と戦います（ロビーで増減できます）
3. 飛行機が島の上を横切ります。島の上で **F** で降下、もう一度 **F**（または高度 85m で自動）でパラシュート
4. 建物の中の武器・弾・回復・装備を拾って（**F**）そろえる。足もとの輪の色がレア度（白 ふつう / 青 いい / 金 すごい）。装備は Lv1 オリーブ / Lv2 銀青 / Lv3 金
   - **補給物資**: 安全地帯が縮み始めるたび（3 回）、次の安全地帯の中にパラシュートで降りてくる（地図に □、着地すると赤い煙）。中身は**探知機**で、**7** で使うと 5 秒間、地図にみんなの位置が赤い ● で出る
   - **名所**: まん中の町の広場（巨大ハス君像と鳥居）、見張り台（長い階段で高さ 8m の台へ。上には良い武器）、ピンクの**ジャンプ台**（乗ると約 14m 跳ぶ。2 階建ての屋根も越えられる）、巨大看板、町をつなぐ道
   - グレネードを持つと、投げた時の**予測線**（爆発する所と届く範囲の輪）が出る。飛んでいるグレネードは、自分のものは手元で同じ物理を動かし、ほかの人のものは人と同じように補間してなめらかに描く
5. 青い壁（安全地帯）の外にいると体力が減ります。白い点線（次の安全地帯）へ移動しよう。地図は **M**
6. 最後の 1 人になったら「勝った！勝った！今夜はハス勝だ！！」

## おまけモード

- **チーム戦**（ロビーでホストが選ぶ）: 人間みんなのチーム vs CPU みんなのチーム。CPU もふつうに武器を拾って銃で戦う。
  味方には弾もグレネードも当たらない。どちらかのチームが全滅したら決着。敵の名前は赤、味方は水色。左上は「人間 / CPU」の残り人数
- **射撃訓練場**（タイトルのボタン。ひとりで、通信なし）: 飛行機・安全地帯なし。足もとに全部の武器・アタッチメント・弾・Lv3 の装備・回復が並ぶ。
  前方の見通しのよい方向に 10・20・35・50・75・100・150・200m の的（防具の Lv がばらばら。いくつかは左右に動く）。的は倒れず、自分も倒れない。
  当てると照準の横にダメージの数字（頭は赤、倒したぶんは金色）が出るので、武器・アタッチメント・距離・防具ごとの違いを試せる

## 画面の見かた

- 照準: 腰だめは広がる十字。のぞきこむ（右クリック）と、付いているサイトで変わる
  - なし: アイアンサイト（照門の間に黄色い先の照星）/ レッドドット: 窓の中の赤い点 / 2 倍: 赤い山形 / 4 倍: 目盛りつきの十字と赤い点 / 8 倍: 細い十字と距離の目盛り
  - のぞきこむと、サイトの高さがちょうど画面の中心に来るように銃が下がる（銃で照準が隠れない）
- 撃たれた時の向き: ほかの人の弾の線は、その人の見えている銃口から、姿と同じ時刻に出る（体の向きと弾の向きがずれない）
- やられた時: 「やっちまった！」の画面（誰に・何で・何 m・ヘッドショットか・順位・キル・ダメージ）と、倒した人の肩ごしのキルカメラ（倒される 4 秒前から。弾の線も再生。クリック / Space で飛ばす）。そのあと倒した人を観戦（観戦中は見ている人の体力が出る）
- 撃たれた時: 量に応じて画面が赤く光り、血しぶき・カメラの揺れ・撃たれた向きの赤い印。体力バーは数字つきで、減った分が白く残ってから縮む
- 持ち物の欄（ヘルメット・ベスト・バッグ・包帯・救急キット・ドリンク）: アイテムの 3D の形をその場で描いた絵（[js/icons.js](js/icons.js)）。どれにもハス君スタンプの印が付いている（ヘルメット「不可能です！」/ ベスト「座禅する！」/ バッグ「準備完了！」/ 包帯「寝る子は育つ」/ 救急キット「母は偉大なり！」/ ドリンク「今日はチートデイ」）。落ちている物・キャラが着ている装備にも同じ印
- 体力が少ない時: 60 未満で画面の縁が赤く、50 未満で色が抜け、25 未満で縁が脈打ち心音が鳴る

## 通信のしくみと安全対策

- ルーム番号 5 桁 → ホストの Peer ID `huspubg-v1-12345`（`v1` は [js/version.js](js/version.js) の `PROTOCOL`。版の違う人どうしはつながらない）
- 接続は `reliable: false`、`serialization: "raw"`（PeerJS に JSON / BinaryPack の解読をさせない）。それ以外の形の接続はすぐ切る（[js/net.js](js/net.js)）
- 受け取ったものは必ず [js/protocol.js](js/protocol.js) を通す
  - 文字列で、長さが上限以内（クライアント → ホスト 1,500 文字、ホスト → クライアント 16,000 文字）。超えたら読まずに捨てる
  - JSON として読めるただのオブジェクトで、決まった種類（`t`）だけ
  - 決まったフィールドだけを取り出して新しいオブジェクトを作り直す（`__proto__` などは残らない）。数値は有限・範囲内に丸め、配列は長さを確かめ、名前は制御文字・書字方向の制御文字・`<>&"'` を消して 10 文字まで
  - 表示は `textContent` だけ（HTML として扱わない）
- 1 秒あたりの受信数に上限（ためられるのは 60 通、毎秒 150 通）。送りすぎる相手・8 秒黙っている相手は切る。まだ開いていない接続は 6 本まで
- **自分の移動だけは手元が正、それ以外はホストが正**: 体力・持ち物・当たり判定・安全地帯・落ちているもの・ほかの人の位置はホストが決める
  - 自分の体は手元で動かして位置を申告するので、回線が遅くても操作はすぐ反応する
  - ホストの速さの検査は「貯金」方式: 待った時間のぶんだけ動いてよい距離が貯まる（最大 2.5 秒ぶん）。申告が遅れてまとめて届いても、正しい動きなら戻されない。
    戻すのは明らかな瞬間移動・速すぎる移動だけ（試験: 40% 欠落 + 最大 0.8 秒の遅れでも戻されず、2 倍速は戻される）
  - 射撃は「銃口と向き」だけ送る。ホストは連射の速さ・弾数・銃口の位置・散弾の広がりを確かめ、撃った人が見ていた時刻（最大 0.6 秒前）までみんなの位置を巻き戻して判定する
  - 拾う・回復・装填などはホストが距離や条件を確かめる
- `reliable: false` で落ちても困らないように、位置は毎回まるごと送り、落ちているもの・撃破などの「できごと」は番号付きで、相手が受け取ったと返事するまで毎回送り直す
- ほかの人の動き: ホストは毎秒 30 回計算して配る（座標は 10cm 単位に丸めて軽くする。24 人で 1 通 約 1.8KB）。自分の位置の申告も毎秒 30 回
  - 受け取った側は少し遅らせて補間する。遅らせる量は届く間隔の揺れから自動で決める（70〜250ms。悪くなったらすぐ増やし、良くなったらゆっくり減らす）
  - 次が届かない間は、直前の動きから最大 150ms 先まで先読みする（止まって見えないように）

## CPU

- 安全地帯: 「次の安全地帯まで走ってかかる時間」と残り時間をくらべ、間に合わなくなる前に動き出す。地帯の外では撃ち合い中でも中へ向かいながら撃ち、回復はドリンクを走りながら
- 道: [js/nav.js](js/nav.js) の道さがしで扉から家に入る。2 階と見張り台は階段の点をたどる。引っかかったら道を作り直し、何度もだめなら目的をあきらめる
- そのほか: 隠れた敵にグレネードを投げこむ / 探知機を使って近い敵へ向かう / 補給物資を取りに行く
- 試験（射撃なしで 24 体 × 6 試合）: 最終段階（半径 0）より前に安全地帯で死んだ CPU は 0

## 不具合への備え

- 空中（降下中・ジャンプ中）で倒れた人は、真下の地面（屋根の上なども）に下ろしてから倒れる
- パラシュート中も建物の壁を通りぬけない。体が壁や岩に埋まったら、毎フレーム近くの空いている所へ出す（CPU も）
- カメラの向きや位置が壊れた（NaN）時は、直前の正しい値に戻す（画面が空の色だけになるのを防ぐ）

## 注意

- ホストはタブを表に出しておいてください（裏にするとブラウザがタイマーを遅くし、対戦が止まり気味になります）
- PeerJS の公開サーバーにつながらない環境（社内ネットワークなど）では遊べません
- 動作確認用に、URL の末尾に `#debug` を付けると `window.__S` から状態を見られます
